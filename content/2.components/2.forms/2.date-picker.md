---
title: Date picker
description: A button that opens a calendar to pick one date, with limits, keyboard support and texts in any language.
---

## Usage

Use the `v-model` directive to control the selected date, and the `label` prop to name the date picker and its calendar for screen readers. The date is a `YYYY-MM-DD` string, like `2026-11-26`: it reads the same in every time zone, and goes as is into JSON or an API.

::code-preview
:::div{class="w-full"}
::::k-date-picker{label="Due date" model-value="2026-11-26"}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const dueDate = ref('2026-11-26')
</script>

<template>
  <KDatePicker v-model="dueDate" label="Due date" />
</template>
```
::

The calendar opens on the selected date, or on today, which has a dot under its number. Picking a day closes it.

### Min and max

Use the `min` and `max` props to limit the dates that can be picked. The days outside are dimmed, and the arrows stop at the months of the limits.

::code-preview
:::div{class="w-full"}
::::k-date-picker{label="Transfer date" model-value="2026-11-26" min="2026-11-10" max="2026-12-10"}
::::
:::

#code
```vue
<KDatePicker v-model="transferDate" label="Transfer date" min="2026-11-10" max="2026-12-10" />
```
::

### Disabled dates

Use the `disabled-dates` prop to list the days that cannot be picked: single dates, and `[start, end]` ranges with both ends included. They are dimmed in the calendar.

::code-preview
:::div{class="w-full"}
::::k-date-picker{label="Delivery date" model-value="2026-12-21" :disabled-dates='["2026-12-25", "2027-01-01", ["2026-12-28", "2026-12-31"]]'}
::::
:::

#code
```vue
<KDatePicker
  v-model="deliveryDate"
  label="Delivery date"
  :disabled-dates="['2026-12-25', '2027-01-01', ['2026-12-28', '2026-12-31']]"
/>
```
::

For a rule rather than a list, like weekends, use the `is-date-disabled` prop. It receives each date and returns `true` for the ones that cannot be picked. A day is disabled as soon as `min`, `max`, `disabled-dates` or `is-date-disabled` excludes it.

::code-preview
:date-picker-weekdays-example

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const transferDate = ref<string>()

function isWeekend(isoDate: string) {
  const weekday = new Date(`${isoDate}T00:00:00Z`).getUTCDay()
  return weekday === 0 || weekday === 6
}
</script>

<template>
  <KDatePicker v-model="transferDate" label="Transfer date" placeholder="Pick a weekday" :is-date-disabled="isWeekend" />
</template>
```
::

### Icons

The date picker starts with a calendar icon and ends with `ChevronsUpDown`. Use `leading-icon` and `trailing-icon` to change them, with a [Lucide](https://lucide.dev/guide/packages/lucide-vue-next) icon component, or `null` to remove them.

```vue
<script setup lang="ts">
import { CalendarClock, ChevronDown } from 'lucide-vue-next'
</script>

<template>
  <KDatePicker v-model="dueDate" label="Due date" :leading-icon="CalendarClock" :trailing-icon="ChevronDown" />
  <KDatePicker v-model="dueDate" label="Due date" :leading-icon="null" />
</template>
```

### Custom selection

The selected date is shown in the short format of the locale: `11/26/26` in English. Use the `selection-label` prop to write it yourself from the date, or the `selection` slot to show more than text.

::code-preview
:date-picker-selection-example

#code
```vue
<script setup lang="ts">
const longDateFormat = new Intl.DateTimeFormat('en-US', { weekday: 'short', month: 'short', day: 'numeric', timeZone: 'UTC' })

function formatDeliveryDate(isoDate: string) {
  return `Delivery on ${longDateFormat.format(new Date(`${isoDate}T00:00:00Z`))}`
}
</script>

<template>
  <KDatePicker v-model="deliveryDate" label="Delivery date" :selection-label="formatDeliveryDate" />

  <KDatePicker v-model="meetingDate" label="Meeting date">
    <template #selection="{ selectedDate }">
      {{ selectedDate }}
      <KBadge label="Booked" color="success" />
    </template>
  </KDatePicker>
</template>
```
::

Screen readers hear the label followed by the text of `selection-label`, or the default format: `Delivery date, Delivery on Thu, Nov 26`.

### Forms

Use the `name` prop to send the date with a `<form>`: the date picker adds a hidden input with that name and the `YYYY-MM-DD` date.

```vue
<form action="/invoices" method="post">
  <KDatePicker v-model="dueDate" name="due-date" label="Due date" />
</form>
```

### Translation

The date picker never translates on its own. Its texts come in two kinds.

The fixed texts each have a prop with an English default. Pass your translations to them.

| Prop | Default |
| --- | --- |
| `placeholder` | `Select date...` |
| `clear-label` | `Clear current value`, read by screen readers on the clear button |
| `previous-month-label` | `Previous month`, read by screen readers on the arrow |
| `next-month-label` | `Next month`, read by screen readers on the arrow |

The texts made from the dates follow the `locale` prop, `en-US` by default, through the `Intl` API of the browser. With `locale="fr-FR"`, the month reads `novembre 2026`, the weekdays `lu ma me…` and the selected date `26/11/26`. Use `week-starts-on` to start the weeks on Monday (`1`) instead of Sunday (`0`).

::code-preview
:date-picker-translation-example

#code
```vue
<KDatePicker
  v-model="dueDate"
  label="Échéance"
  locale="fr-FR"
  :week-starts-on="1"
  placeholder="Choisir une date"
  clear-label="Effacer la date"
  previous-month-label="Mois précédent"
  next-month-label="Mois suivant"
  clearable
/>
```
::

To write a generated text yourself, pass a function: it replaces the locale for that text only.

| Prop | Receives | Default in `en-US` |
| --- | --- | --- |
| `weekday-label` | The weekday, from `0` (Sunday) to `6`, like `getDay()` | `Su`, `Mo`… |
| `month-label` | The month, like `2026-11` | `November 2026` |
| `day-label` | The date, like `2026-11-26`, read by screen readers on each day | `Thursday, November 26, 2026` |
| `selection-label` | The selected date | `11/26/26` |

::code-preview
:date-picker-label-functions-example

#code
```vue
<script setup lang="ts">
import type { Weekday } from '@kuina-ui/vue'

const weekdayInitials = ['D', 'L', 'M', 'M', 'J', 'V', 'S']
const monthNames = ['Janv.', 'Févr.', 'Mars', 'Avr.', 'Mai', 'Juin', 'Juil.', 'Août', 'Sept.', 'Oct.', 'Nov.', 'Déc.']

function formatMonthLabel(isoMonth: string) {
  const [year, monthNumber] = isoMonth.split('-').map(Number)
  return `${monthNames[monthNumber - 1]} ${year}`
}
</script>

<template>
  <KDatePicker
    v-model="dueDate"
    label="Échéance"
    locale="fr-FR"
    :week-starts-on="1"
    :weekday-label="(weekday: Weekday) => weekdayInitials[weekday]"
    :month-label="formatMonthLabel"
    :selection-label="(isoDate: string) => isoDate.split('-').reverse().join('.')"
  />
</template>
```
::

The default weekday labels keep the first two letters of the short name of each day. That works for languages written in the Latin alphabet, but not for all of them: in Arabic, for example, pass `weekday-label`.

### Side and align

Use the `side` prop to open the calendar `bottom` (default), `top`, `left` or `right` of the date picker, and the `align` prop to line it up with the `start` (default), the `center` or the `end`.

```vue
<KDatePicker v-model="dueDate" label="Due date" side="top" align="end" />
```

### Flip

When there is not enough room below, the calendar opens above the date picker. Set `flip` to `false` to always keep the side you chose.

```vue
<KDatePicker v-model="dueDate" label="Due date" :flip="false" />
```

### Fixed position

By default, the calendar scrolls with the page. If the date picker sits in an area that does not scroll, like a sticky header, set `strategy` to `fixed` so the calendar stays next to it.

```vue
<KDatePicker v-model="dueDate" label="Due date" strategy="fixed" />
```

### Open state

Use `v-model:open` to know whether the calendar is open, or to open and close it from your code.

::code-preview
:date-picker-open-state-example

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const isCalendarOpen = ref(false)
const dueDate = ref<string>()
</script>

<template>
  <KDatePicker v-model="dueDate" v-model:open="isCalendarOpen" label="Due date" />
  <p>The calendar is {{ isCalendarOpen ? 'open' : 'closed' }}.</p>
</template>
```
::

## Keyboard

| Key | Action |
| --- | --- |
| :kbd{value="Enter"}, :kbd{value="Space"}, :kbd{value="↓"}, :kbd{value="↑"} | On the closed date picker, opens the calendar on the selected date, or today. |
| :kbd{value="←"}, :kbd{value="→"} | Moves to the previous or next day. |
| :kbd{value="↑"}, :kbd{value="↓"} | Moves to the same day of the previous or next week. |
| :kbd{value="Home"}, :kbd{value="End"} | Moves to the first or last day of the week. |
| :kbd{value="PageUp"}, :kbd{value="PageDown"} | Moves to the same day of the previous or next month, or year with :kbd{value="Shift"}. |
| :kbd{value="Enter"}, :kbd{value="Space"} | Picks the focused day. |
| :kbd{value="Esc"} | Closes the calendar and focuses the date picker. |
| :kbd{value="Tab"} | Moves between the arrows and the days, then closes the calendar when the focus leaves it. |

## Animations

The calendar zooms in when it opens, and shrinks as it fades out when it closes. The previous and next months slide in, and the height follows when a month needs one more week. All of them stop when the system asks for reduced motion.

## Customization

Use the `ui` prop to change the classes of each part of the date picker, and `class` for the root element. Your classes always win: `rounded-2xl` replaces the default `rounded-xl` of the calendar instead of being added to it.

::code-preview
:::div{class="w-full"}
::::k-date-picker{label="Rounder" model-value="2026-11-26" :ui='{"panel": "rounded-2xl", "day": "rounded-lg"}'}
::::
:::

#code
```vue
<KDatePicker v-model="dueDate" label="Rounder" :ui="{ panel: 'rounded-2xl', day: 'rounded-lg' }" />
```
::
