title: Select

## Usage

Use the `v-model` directive to control the selected value, and the `options` prop to list the choices. The `label` prop names the select and its list for screen readers.

::code-preview
:::div{class="w-full"}
::::k-select{label="Role" model-value="Editor" :options='["Admin", "Editor", "Viewer"]'}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const role = ref('Editor')
</script>

<template>
  <KSelect v-model="role" label="Role" :options="['Admin', 'Editor', 'Viewer']" />
</template>
```
::

The `v-model` is typed from the options: a list of strings gives a `string`, and options with numeric values give a `number`.

### Options

An option is a string, used as both its value and its label, or an object with a `value` and a `label`. Add a `description` to explain it, and `disabled` to keep it visible but unusable.

::code-preview
:::div{class="w-full"}
::::k-select{label="Plan" model-value="plus" :options='[{"value": "free", "label": "Free", "description": "2 linked accounts · $0"}, {"value": "plus", "label": "Plus", "description": "Unlimited accounts · $4.99/month"}, {"value": "business", "label": "Business", "description": "Team access · Custom pricing", "disabled": true}]'}
::::
:::

#code
```vue
<script setup lang="ts">
import type { SelectOption } from '@kuina-ui/vue'

const planOptions: SelectOption[] = [
  { value: 'free', label: 'Free', description: '2 linked accounts · $0' },
  { value: 'plus', label: 'Plus', description: 'Unlimited accounts · $4.99/month' },
  { value: 'business', label: 'Business', description: 'Team access · Custom pricing', disabled: true },
]
</script>

<template>
  <KSelect v-model="plan" label="Plan" :options="planOptions" />
</template>
```
::

::::
:::

```vue
<script setup lang="ts">
const accountOptions = [
  {
    label: 'Northwind Bank',
    options: [
      { value: 'checking', label: 'Checking ···· 4821', description: '$12,480.20 available' },
      { value: 'savings', label: 'Savings ···· 0937', description: '$31,200.00 available' },

  {
    label: 'Contoso Card',
    options: [{ value: 'credit-card', label: 'Visa ···· 7712', description: '$2,140.65 spent this month' }],
  },

</script>

<template>
  <KSelect v-model="account" label="Account" :options="accountOptions" />
</template>
```

### Option keys

Pass the objects of your API as they are, and tell the select where to read each field with `value-key`, `label-key`, `description-key` and `avatar-key`. A key can follow nested fields with dots, like `contact.email`. The `v-model` gets the type of the field read by `value-key`.

::code-preview
:select-keys-example

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

interface TeamMember {
  id: number
  fullName: string
  contact: { email: string }
}

const teamMembers: TeamMember[] = [
  { id: 1, fullName: 'Avery Collins', contact: { email: 'avery.collins@example.com' } },
  { id: 2, fullName: 'Jordan Reyes', contact: { email: 'jordan.reyes@example.com' } },
  { id: 3, fullName: 'Riley Brooks', contact: { email: 'riley.brooks@example.com' } },
]

const assigneeId = ref<number>(2)
</script>

<template>
  <KSelect
    v-model="assigneeId"
    label="Assignee"
    :options="teamMembers"
    value-key="id"
    label-key="fullName"
    description-key="contact.email"
  />
</template>
```
::

### Avatars

Give an option an `avatar` to show a photo, initials or an icon before its label. A string is the URL of a photo. An object takes the props of [Avatar](/components/elements/avatar): `imageUrl`, `initials`, `icon`, `color`, `variant` and `pill`, which you set to `false` for a square avatar, like a bank logo. Without a photo or initials, the avatar shows the first letter of the label.

::code-preview
:select-avatars-example

#code
```vue
<script setup lang="ts">
import type { SelectOption } from '@kuina-ui/vue'
import { CreditCard, Landmark, UserRoundX } from 'lucide-vue-next'

const memberOptions: SelectOption[] = [
  { value: 'avery-collins', label: 'Avery Collins', avatar: '/avatars/avery-collins.webp' },
  { value: 'jordan-reyes', label: 'Jordan Reyes', avatar: '/avatars/jordan-reyes.webp' },
  { value: 'drew-parker', label: 'Drew Parker', avatar: { initials: 'DP', color: 'info' } },
  { value: 'unassigned', label: 'Unassigned', avatar: { icon: UserRoundX } },
]

const paymentAccountOptions: SelectOption[] = [
  { value: 'northwind', label: 'Northwind Bank', description: 'Checking ···· 4821', avatar: { icon: Landmark, color: 'info', pill: false } },
  { value: 'contoso', label: 'Contoso Card', description: 'Visa ···· 7712', avatar: { icon: CreditCard, color: 'discovery', pill: false } },
]
</script>

<template>
  <KSelect v-model="assignee" label="Assignee" :options="memberOptions" />
  <KSelect v-model="paymentAccount" label="Payment account" :options="paymentAccountOptions" variant="soft" :pill="false" />
</template>
```
::

The avatar follows the size of the select. The selected avatar also shows in the select itself, from the `md` size up, when only one option can be chosen.

### Multiple

Add `multiple` to let several options be chosen: the `v-model` becomes an array, and the list stays open after each choice. The select shows the selected labels, cut with an ellipsis when they do not fit.

Use `selection-label` to write your own text from the selected options, like a count. It receives the options as you passed them, so you can translate it, or show the labels up to a number and a count beyond. Screen readers still hear every selected label.

::code-preview
:select-multiple-example

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const categoryOptions = ['Groceries', 'Dining', 'Transport', 'Travel', 'Subscriptions', 'Utilities']

const categories = ref(['Groceries', 'Dining', 'Transport'])
</script>

<template>
  <KSelect v-model="categories" label="Categories" :options="categoryOptions" multiple />
  <KSelect
    v-model="categories"
    label="Categories"
    :options="categoryOptions"
    multiple
    :selection-label="(selectedCategories) => `${selectedCategories.length} categories`"
  />
</template>
```
::

### Search

Add `searchable` to put a search input at the top of the list. It keeps the options whose label contains the search, and hides the groups left empty. Use `search-placeholder` to change its text, `Search...` by default.

::code-preview
:::div{class="w-full"}
::::k-select{label="Country" model-value="Madagascar" searchable search-placeholder="Search countries" :options='["Canada", "France", "Germany", "Japan", "Madagascar", "United Kingdom", "United States"]'}
::::
:::

#code
```vue
<KSelect
  v-model="country"
  label="Country"
  :options="countryOptions"
  searchable
  search-placeholder="Search countries"
/>
```
::

Set `search-placement` to `field` to type straight into the select instead: the list opens as you type, and the search input leaves the list. The select keeps showing the selected label, even once the list is open, until you type: the first letter, a paste or :kbd{value="Backspace"} starts a new search, so nothing moves when you click. While the search is empty, the selection shows in grey as its placeholder, or `search-placeholder` when nothing is selected.

::code-preview
:::div{class="grid w-full items-start gap-4 sm:grid-cols-2"}
::::k-select{label="Country" model-value="Japan" searchable search-placeholder="Search countries" :options='["Canada", "France", "Germany", "Japan", "Madagascar", "United Kingdom", "United States"]'}
::::

::::k-select{label="Country" model-value="Madagascar" searchable search-placement="field" search-placeholder="Type a country" :options='["Canada", "France", "Germany", "Japan", "Madagascar", "United Kingdom", "United States"]'}
::::
:::

#code
```vue
<KSelect v-model="country" label="Country" :options="countryOptions" searchable search-placeholder="Search countries" />
<KSelect v-model="country" label="Country" :options="countryOptions" searchable search-placement="field" search-placeholder="Type a country" />
```
::

To use your own input, fill the `search` slot and bind `searchAttributes` on it: they hold the search, update it as you type, move through the list with the keyboard and link the input to the list for screen readers.

```vue
<KSelect v-model="country" label="Country" :options="countryOptions" searchable>
  <template #search="{ searchAttributes }">
    <input v-bind="searchAttributes" class="h-10 w-full bg-transparent px-3 outline-hidden" />
  </template>
</KSelect>
```

### Actions

Use `actions` to add buttons below the options, like linking a new account. Each action has a `label`, an optional `icon` and an `onSelect` function. Choosing an action runs it and closes the list.

```vue
</script>

<template>
  <KSelect v-model="account" label="Account" :options="accountOptions" :leading-icon="Wallet" :actions="accountActions" />
</template>
```

### Custom content

Use the `option` slot to draw an option your way, with the option as you passed it and whether it is `selected`. The check mark stays before your content. Use the `selection` slot to draw the selected value in the select.

::code-preview
:select-slots-example

#code
```vue
<script setup lang="ts">
interface SubscriptionPlan {
  value: string
  label: string
  monthlyPrice: string
  popular?: boolean
}

const planOptions: SubscriptionPlan[] = [
  { value: 'free', label: 'Free', monthlyPrice: '$0' },
  { value: 'plus', label: 'Plus', monthlyPrice: '$4.99', popular: true },
  { value: 'business', label: 'Business', monthlyPrice: '$19' },
]
</script>

<template>
  <KSelect v-model="plan" label="Plan" :options="planOptions">
    <template #option="{ option }">
      <span class="flex min-w-0 flex-1 items-center gap-2">
        <span class="flex-1">{{ option.label }}</span>
        <KBadge v-if="option.popular" label="Popular" color="discovery" size="sm" />
        <span class="font-normal text-muted">{{ option.monthlyPrice }}/month</span>
      </span>
    </template>
    <template #selection="{ selectedOptions }">
      <template v-if="selectedOptions[0]">{{ selectedOptions[0].label }} · {{ selectedOptions[0].monthlyPrice }}/month</template>
      <template v-else>Choose a plan</template>
    </template>
  </KSelect>
</template>
```

### Translation

The select never translates on its own: each text it shows has a prop with an English default. Pass your translations to these props, as plain text, or as a function when the text depends on a value.

| Prop | Default |
| --- | --- |
| `placeholder` | `Select...` |
| `search-placeholder` | `Search...` |
| `loading-placeholder` | `Loading...` |
| `clear-label` | `Clear current value`, read by screen readers on the clear button |
| `no-results-label` | `No results for “…”`, with the search in the quotes |
| `selection-label` | The selected labels, separated by commas |

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <KSelect
    v-model="categories"
    :label="t('categories.label')"
    :options="categoryOptions"
    multiple
    searchable
    :placeholder="t('select.placeholder')"
    :search-placeholder="t('select.search')"
    :clear-label="t('select.clear')"
    :no-results-label="(searchQuery) => t('select.noResults', { searchQuery })"
    :selection-label="(selectedCategories) => t('categories.selected', selectedCategories.length)"
  />
</template>
```

### Side and align

Use the `side` prop to open the list `bottom` (default), `top`, `left` or `right` of the select, and the `align` prop to line it up with the `start` (default), the `center` or the `end`. The list is as wide as the select, and at least `16rem`.

```vue
<KSelect label="Date range" :options="dateRangeOptions" side="top" align="end" />
```

### Flip

When there is not enough room below, the list opens above the select. Set `flip` to `false` to always keep the side you chose.

```vue
<KSelect label="Date range" :options="dateRangeOptions" :flip="false" />
```

### Fixed position

By default, the list scrolls with the page. If the select sits in an area that does not scroll, like a sticky header or a fixed sidebar, set `strategy` to `fixed` so the list stays next to it.

```vue
<KSelect label="Workspace" :options="workspaceOptions" strategy="fixed" />
```

## Keyboard

| Key | Action |
| --- | --- |
| :kbd{value="Enter"}, :kbd{value="Space"}, :kbd{value="↓"} | On the closed select, opens the list on the selected option, or the first one. |
| :kbd{value="↑"} | On the closed select, opens the list on the selected option, or the last one. |
| :kbd{value="↓"}, :kbd{value="↑"} | In the list, moves to the next or previous option, then to the actions. |
| :kbd{value="Home"}, :kbd{value="End"} | Without search, moves to the first or last item. |
| :kbd{value="Enter"} | Selects the highlighted option or runs the highlighted action. :kbd{value="Space"} does the same without search. |
| A letter | Without search, moves to the next option starting with that letter. On a closed select with search, opens it and starts the search with that letter. |
| :kbd{value="Esc"} | Closes the list and focuses the select. |
| :kbd{value="Tab"} | Closes the list and moves on from the select. |

With `search-placement="field"`, the keys that edit text keep their usual role: letters and :kbd{value="Space"} type, :kbd{value="Home"} and :kbd{value="End"} move the cursor, and :kbd{value="↓"} or :kbd{value="↑"} open the list.

### Options

`SelectOptionEntry` is a string, an option or a group.

| Entry | Fields |
| --- | --- |
| Option | `value`, `label`, `description?`, `disabled?`, `avatar?: string \| { imageUrl?, initials?, icon?, color?, variant?, pill? }` |
| Group | `label`, `options` |

With `value-key`, `label-key`, `description-key` or `avatar-key`, the option can be any object: these fields are read from the keys you gave.

A `SelectAction` has a `label`, an `icon?` and an `onSelect?(event)`.

### Slots

| Slot | Props | Description |
| --- | --- | --- |
| `option` | `{ option, selected }` | Replaces the content of each option, after its check mark. |
| `selection` | `{ selectedOptions }` | Replaces the selected value shown in the select. |
| `search` | `{ searchAttributes }` | Replaces the search input. Bind `searchAttributes` on your input. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | The selected value, or an array of values with `multiple` |
| `update:open` | `boolean` |
