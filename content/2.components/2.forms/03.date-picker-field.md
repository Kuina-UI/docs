---
title: Date picker field
description: A date picker with a floating label, a hint and an error message, made for forms.
---

## Usage

Use the `v-model` directive to control the selected date, a `YYYY-MM-DD` string. The date picker field opens the same calendar as the [Date picker](/components/forms/date-picker), and lines up with a [Text field](/components/forms/text-field) or a [Select field](/components/forms/select-field) of the same size.

::code-preview
:::div{class="w-full"}
::::k-date-picker-field{label="Due date" model-value="2026-11-26"}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const dueDate = ref('2026-11-26')
</script>

<template>
  <KDatePickerField v-model="dueDate" label="Due date" />
</template>
```
::

### Label

Use the `label` prop to name the field. The label sits inside the field while it is empty, and moves up onto the border on focus, while the calendar is open, or once a date is selected.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-date-picker-field{label="Due date"}
::::

::::k-date-picker-field{label="Due date" model-value="2026-11-26"}
::::
:::

#code
```vue
<KDatePickerField v-model="dueDate" label="Due date" />
```
::

### Float label

Set `float-label` to `always` to keep the label on the border at all times, with no animation. The `placeholder` then stays visible while no date is selected. With `auto`, the default, the placeholder only shows once the label has moved up.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-date-picker-field{label="Due date" float-label="always"}
::::

::::k-date-picker-field{label="Due date" placeholder="Pick a due date" float-label="always"}
::::
:::

#code
```vue
<KDatePickerField v-model="dueDate" label="Due date" float-label="always" />
<KDatePickerField v-model="dueDate" label="Due date" placeholder="Pick a due date" float-label="always" />
```
::

### Typing

Set `editable` to let people type the date in the field, which is faster than browsing the calendar to go back a few years. Only digits are needed: the separators are added while typing, so `11022026` becomes `11/02/2026`. The order and the separator follow the `locale`: day first in `fr-FR`, dots in `de-DE`. Phones show the number keyboard.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-date-picker-field{label="Date of birth" editable}
::::

::::k-date-picker-field{label="Date de naissance" locale="fr-FR" placeholder="JJ/MM/AAAA" editable}
::::
:::

#code
```vue
<KDatePickerField v-model="birthDate" label="Date of birth" editable />
<KDatePickerField v-model="birthDate" label="Date de naissance" locale="fr-FR" placeholder="JJ/MM/AAAA" editable />
```
::

- The `v-model` changes as soon as the typed date is complete, real and allowed by `min`, `max`, `disabled-dates` and `is-date-disabled`. An impossible date, like `02/30/2026`, or a disabled one turns the field red.
- When the focus leaves the field, an incomplete or refused date is replaced by the last valid one. Erasing the text clears the date.
- A pasted date is read too, as `2026-11-02` or in the order of the locale, like `11/2/2026`.
- Clicking the field opens the calendar and keeps the focus in it, so you can type or pick. :kbd{value="↓"} moves into the calendar.
- The year has four digits while typing, so the field shows `11/02/2026` instead of `11/02/26`. `selection-label` and the `selection` slot are not used in this mode, because the field shows what is typed.
- The `placeholder` shows the expected format, `MM/DD/YYYY` by default, built from the `locale`. Pass your own text to translate its letters, like `JJ/MM/AAAA`.
- The typing goes through the same mask as [useMask](/composables/use-mask), with a pattern built from the `locale`, like `##/##/####`.

### Hint

Use the `hint` prop to show a help text below the field. It is linked to the field with `aria-describedby`.

::code-preview
:::div{class="w-full"}
::::k-date-picker-field{label="Due date" hint="Payments made after this date are late."}
::::
:::

#code
```vue
<KDatePickerField v-model="dueDate" label="Due date" hint="Payments made after this date are late." />
```
::

### Error message

Use the `error-message` prop to show an error below the field. It replaces the hint, turns the field red and sets `aria-invalid`. Use the `invalid` prop to mark the field as invalid without a message.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-date-picker-field{label="Start date" error-message="Choose a date after today."}
::::

::::k-date-picker-field{label="Start date" model-value="2026-11-02" invalid}
::::
:::

#code
```vue
<KDatePickerField v-model="startDate" label="Start date" error-message="Choose a date after today." />
<KDatePickerField v-model="startDate" label="Start date" invalid />
```
::

### Dates

The date picker field takes the same date props as the [Date picker](/components/forms/date-picker#min-and-max): `min`, `max`, `disabled-dates` and `is-date-disabled` to dim days, `selection-label` or the `selection` slot to write the selected date yourself, and `locale`, `week-starts-on` and the label functions for [translation](/components/forms/date-picker#translation).

::code-preview
:::div{class="w-full"}
::::k-date-picker-field{label="Delivery date" model-value="2026-12-21" min="2026-12-01" :disabled-dates='["2026-12-25", ["2026-12-28", "2026-12-31"]]'}
::::
:::

#code
```vue
<KDatePickerField
  v-model="deliveryDate"
  label="Delivery date"
  min="2026-12-01"
  :disabled-dates="['2026-12-25', ['2026-12-28', '2026-12-31']]"
/>
```
::

### Pill

Date picker fields are pills by default. Set `pill` to `false` to get rounded corners that follow the size.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-date-picker-field{label="Pill" model-value="2026-11-26"}
::::

::::k-date-picker-field{label="Rounded" model-value="2026-11-26" :pill="false"}
::::
:::

#code
```vue
<KDatePickerField label="Pill" />
<KDatePickerField label="Rounded" :pill="false" />
```
::

### Icons

The field starts with a calendar icon and ends with `ChevronsUpDown`. Use `leading-icon` and `trailing-icon` to change them, with a [Lucide](https://lucide.dev/guide/packages/lucide-vue-next) icon component, or `null` to remove them.

```vue
<KDatePickerField v-model="dueDate" label="Due date" :leading-icon="null" />
```

### Forms

Use the `name` prop to send the date with a `<form>`: the field adds a hidden input with that name and the `YYYY-MM-DD` date. Use the `id` prop to give the field your own ID, for example to point a link at it.

```vue
<form action="/invoices" method="post">
  <KDatePickerField v-model="dueDate" id="due-date" name="due-date" label="Due date" />
</form>
```

## Keyboard

The keys are the same as on the [Date picker](/components/forms/date-picker#keyboard). With `editable`, the text keys type in the field, :kbd{value="↓"} moves into the calendar and :kbd{value="Esc"} closes it.

## Customization

Use the `ui` prop to change the classes of each part of the field, and `class` for the root element.

::code-preview
:::div{class="w-full"}
::::k-date-picker-field{label="Due date" model-value="2026-11-26" :ui='{"label": "font-medium", "panel": "rounded-2xl"}'}
::::
:::

#code
```vue
<KDatePickerField v-model="dueDate" label="Due date" :ui="{ label: 'font-medium', panel: 'rounded-2xl' }" />
```
::

## API

### Props

The date picker field has every prop of the [Date picker](/components/forms/date-picker#props), except `block`, with these differences.

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | `useId()` |
| `editable` | `boolean` | `false` |
| `placeholder` | `string` | The format, like `MM/DD/YYYY`, with `editable` |
| `floatLabel` | `'auto' \| 'always'` | `'auto'` |
| `hint` | `string` | |
| `errorMessage` | `string` | |
| `variant` | `'outline' \| 'soft'` | `'outline'` |
| `size` | `'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl'` | `'4xl'` |
| `ui` | `{ root?, container?, base?, leadingIcon?, value?, placeholder?, selectionText?, trailing?, clearButton?, clearIcon?, trailingIcon?, label?, hint?, errorMessage?, errorIcon? }`, plus the calendar parts of the [Date picker](/components/forms/date-picker#props) | |

### Slots

| Slot | Props | Description |
| --- | --- | --- |
| `selection` | `{ selectedDate }` | Replaces the selected date shown in the field. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `string \| undefined` |
| `update:open` | `boolean` |
