---
title: Textarea
description: A multi-line text input with a floating label, for notes, messages and descriptions.
---

## Usage

Use the `v-model` directive to control the value of the textarea.

::code-preview
:::div{class="w-full"}
::::k-textarea{label="Note" model-value="Team lunch with the design studio after the quarterly review, split three ways."}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const note = ref('Team lunch with the design studio after the quarterly review, split three ways.')
</script>

<template>
  <KTextarea v-model="note" label="Note" />
</template>
```
::

### Label

Use the `label` prop to name the textarea. The label sits on the first line while the textarea is empty, and moves up onto the border on focus or once it has a value.

::code-preview
:::div{class="w-full"}
::::k-textarea{label="Note"}
::::
:::

#code
```vue
<KTextarea label="Note" />
```
::

### Float label

Set `float-label` to `always` to keep the label on the border at all times, with no animation. The textarea can then show a `placeholder`, which only appears in this mode.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-textarea{label="Note" float-label="always"}
::::

::::k-textarea{label="Note" placeholder="Add details for your accountant" float-label="always"}
::::
:::

#code
```vue
<KTextarea label="Note" float-label="always" />
<KTextarea label="Note" placeholder="Add details for your accountant" float-label="always" />
```
::

### Rows

Use the `rows` prop to set the height of the textarea, in lines. Defaults to `3`.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-textarea{label="Two rows" :rows="2"}
::::

::::k-textarea{label="Five rows" :rows="5"}
::::
:::

#code
```vue
<KTextarea label="Two rows" :rows="2" />
<KTextarea label="Five rows" :rows="5" />
```
::

### Auto resize

Set `auto-resize` to let the textarea grow with its content, from `rows` up to `max-rows` lines. `max-rows` defaults to `10`. It relies on the CSS `field-sizing` property: in browsers that do not support it, the textarea keeps the height set by `rows`.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-textarea{label="Message to support" :rows="1" auto-resize :max-rows="6"}
::::

::::k-textarea{label="Message to support" :rows="1" auto-resize :max-rows="6" model-value="Hi, a card payment of $42.90 at the airport bookshop appears twice on my statement. The second charge is dated a day later and I only made one purchase. Could you look into it and refund the duplicate? Thanks!"}
::::
:::

#code
```vue
<KTextarea v-model="message" label="Message to support" :rows="1" auto-resize :max-rows="6" />
```
::

### Variant

Use the `variant` prop to change the look of the textarea: `outline` (default) or `soft`.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-textarea{label="Outline" variant="outline"}
::::

::::k-textarea{label="Soft" variant="soft"}
::::
:::

#code
```vue
<KTextarea label="Outline" variant="outline" />
<KTextarea label="Soft" variant="soft" />
```
::

### Size

Use the `size` prop to change the size of the textarea, from `md` to `4xl`. Defaults to `4xl`.

::code-preview
:::div{class="flex w-full flex-col gap-6"}
::::k-textarea{label="md" size="md" :rows="2"}
::::

::::k-textarea{label="lg" size="lg" :rows="2"}
::::

::::k-textarea{label="xl" size="xl" :rows="2"}
::::

::::k-textarea{label="2xl" size="2xl" :rows="2"}
::::

::::k-textarea{label="3xl" size="3xl" :rows="2"}
::::

::::k-textarea{label="4xl" size="4xl" :rows="2"}
::::
:::

#code
```vue
<KTextarea label="md" size="md" :rows="2" />
<KTextarea label="2xl" size="2xl" :rows="2" />
<KTextarea label="4xl" size="4xl" :rows="2" />
```
::

### Pill

Textareas have large rounded corners by default. Set `pill` to `false` to get tighter corners that follow the size.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-textarea{label="Pill"}
::::

::::k-textarea{label="Rounded" :pill="false"}
::::
:::

#code
```vue
<KTextarea label="Pill" />
<KTextarea label="Rounded" :pill="false" />
```
::

### Hint

Use the `hint` prop to show a help text below the textarea. It is linked to the textarea with `aria-describedby`.

::code-preview
:::div{class="w-full"}
::::k-textarea{label="Transfer reference" hint="Shown to the recipient on their bank statement."}
::::
:::

#code
```vue
<KTextarea label="Transfer reference" hint="Shown to the recipient on their bank statement." />
```
::

### Error message

Use the `error-message` prop to show an error below the textarea. It replaces the hint, turns the textarea red and sets `aria-invalid`. Use the `invalid` prop to mark the textarea as invalid without a message.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-textarea{label="Reason for the dispute" model-value="Wrong" error-message="Describe the issue in at least 20 characters."}
::::

::::k-textarea{label="Reason for the dispute" model-value="Wrong" invalid}
::::
:::

#code
```vue
<KTextarea label="Reason for the dispute" error-message="Describe the issue in at least 20 characters." />
<KTextarea label="Reason for the dispute" invalid />
```
::

### Disabled

Use the `disabled` prop to disable the textarea.

::code-preview
:::div{class="w-full"}
::::k-textarea{label="Account notes" model-value="Joint account opened in March 2024." disabled}
::::
:::

#code
```vue
<KTextarea label="Account notes" disabled />
```
::

## Examples

### With character limit

Set `maxlength` to limit the number of characters. A counter shows how many are used, next to the hint.

::code-preview
:::div{class="w-full"}
::::k-textarea{label="Budget description" model-value="Groceries, fuel and small household expenses for the month." :maxlength="140" hint="Keep it short, it appears on the budget card."}
::::
:::

#code
```vue
<KTextarea
  v-model="budgetDescription"
  label="Budget description"
  :maxlength="140"
  hint="Keep it short, it appears on the budget card."
/>
```
::

### On a card

The floating label covers the border with the `canvas` color on its top half, to blend with the page background. On another surface, like a card, change that color with the `ui` prop.

::code-preview
:::div{class="w-full rounded-xl border border-line bg-widget p-6"}
::::k-textarea{label="Note" model-value="Team lunch with the design studio." :ui='{"label": "from-widget"}'}
::::
:::

#code
```vue
<KTextarea v-model="note" label="Note" :ui="{ label: 'from-widget' }" />
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | |
| `modelValue` | `string` | |
| `id` | `string` | `useId()` |
| `placeholder` | `string` | |
| `rows` | `number` | `3` |
| `autoResize` | `boolean` | `false` |
| `maxRows` | `number` | `10` |
| `maxlength` | `number` | |
| `variant` | `'outline' \| 'soft'` | `'outline'` |
| `size` | `'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl'` | `'4xl'` |
| `pill` | `boolean` | `true` |
| `floatLabel` | `'auto' \| 'always'` | `'auto'` |
| `hint` | `string` | |
| `errorMessage` | `string` | |
| `invalid` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, container?, base?, label?, footer?, hint?, errorMessage?, errorIcon?, characterCount? }` | |
| `class` | `string` | |

Other attributes, like `name`, `readonly` or `autofocus`, and listeners like `@blur` go to the `<textarea>`.
