---
title: Range slider
description: Pick a range between two values, by dragging its two thumbs, with the keyboard or by typing them.
---

## Usage

Use the `v-model` directive to control the range, as a `[start, end]` tuple, and the `min`, `max` and `step` props to set its limits. They default to `0`, `100` and `1`. Without a value, the range covers everything from `min` to `max`.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Transaction amount" :min="0" :max="5000" :step="50" prefix-unit="$" :model-value="[500, 2000]"}
::::
:::

#code
```vue
<script setup lang="ts">
import type { SliderRange } from '@kuina-ui/vue'
import { ref } from 'vue'

const transactionAmount = ref<SliderRange>([500, 2000])
</script>

<template>
  <KRangeSlider v-model="transactionAmount" label="Transaction amount" :max="5000" :step="50" prefix-unit="$" />
</template>
```
::

It works like the [slider](/components/forms/slider), with two thumbs and two value fields. Each field can be typed in: its end follows 250ms after you stop typing, and is rounded and kept in its bounds when the field loses the focus.

### Label

Use the `label` prop for a plain text label, or the `label` slot for anything else, like a [tooltip](/components/overlays/tooltip). The label names the whole range for screen readers.

The thumbs and the fields of each end are named by `startLabel` and `endLabel`, which default to `Minimum` and `Maximum`. Change them to translate the slider.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Montant de la transaction" start-label="Montant minimum" end-label="Montant maximum" :min="0" :max="5000" :step="50" unit="€" :model-value="[500, 2000]"}
::::
:::

#code
```vue
<KRangeSlider
  v-model="transactionAmount"
  label="Montant de la transaction"
  start-label="Montant minimum"
  end-label="Montant maximum"
  :max="5000"
  :step="50"
  unit="€"
/>
```
::

### Units

Use the `prefixUnit` prop to show a unit before each value, and `unit` to show one after the range.

::code-preview
:::div{class="flex flex-wrap gap-x-12 gap-y-8"}
::::k-range-slider{class="w-75" label="Interest rate" :min="0" :max="20" :step="0.5" unit="%" :model-value="[3.5, 8]"}
::::

::::k-range-slider{class="w-75" label="Settlement delay" :min="0" :max="10" unit="days" :model-value="[1, 3]"}
::::
:::

#code
```vue
<KRangeSlider v-model="interestRate" label="Interest rate" :max="20" :step="0.5" unit="%" />
<KRangeSlider v-model="settlementDelay" label="Settlement delay" :max="10" unit="days" />
```
::

### Minimum range

The thumbs can meet but never cross. Use the `minRange` prop to keep them a given distance apart, in the same unit as the values.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Transaction amount" :min="0" :max="5000" :step="50" :min-range="500" prefix-unit="$" :model-value="[1500, 2000]"}
::::
:::

#code
```vue
<KRangeSlider
  v-model="transactionAmount"
  label="Transaction amount"
  :max="5000"
  :step="50"
  :min-range="500"
  prefix-unit="$"
/>
```
::

### Reset value

Use the `resetValue` prop to offer a way back to a default range. A reset button appears next to the values when the pointer is over the slider, or while one of its fields or thumbs has the keyboard focus, as long as one end differs from `resetValue`. Its `resetLabel` defaults to `Reset to default`.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Transaction amount" :min="0" :max="5000" :step="50" :reset-value="[0, 5000]" prefix-unit="$" :model-value="[500, 2000]"}
::::
:::

#code
```vue
<KRangeSlider
  v-model="transactionAmount"
  label="Transaction amount"
  :max="5000"
  :step="50"
  :reset-value="[0, 5000]"
  prefix-unit="$"
/>
```
::

### Marks

Use the `marks` prop to label values under the track. They behave like the [slider marks](/components/forms/slider#marks).

::code-preview
:::div{class="w-100 max-w-full"}
::::k-range-slider{label="Accepted risk levels" :min="1" :max="5" :model-value="[2, 4]" :marks='[{"value": 1, "label": "1"}, {"value": 2, "label": "2"}, {"value": 3, "label": "3"}, {"value": 4, "label": "4"}, {"value": 5, "label": "5"}]'}
::::
:::

#code
```vue
<KRangeSlider v-model="acceptedRiskLevels" label="Accepted risk levels" :min="1" :max="5" :marks="riskLevelMarks" />
```
::

### Colors

Use the `trackColor` and `rangeColor` props to change the color of the track and of the part between the thumbs, which also colors the thumb rings. They accept any CSS color.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Transaction amount" :min="0" :max="5000" :step="50" prefix-unit="$" :model-value="[500, 2000]" range-color="var(--color-primary)"}
::::
:::

#code
```vue
<KRangeSlider v-model="transactionAmount" label="Transaction amount" :max="5000" :step="50" prefix-unit="$" range-color="var(--color-primary)" />
```
::

### Disabled

Use the `disabled` prop to disable the thumbs and the value fields.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Refund amount" :min="0" :max="2000" :step="50" prefix-unit="$" :model-value="[100, 900]" disabled}
::::
:::

#code
```vue
<KRangeSlider v-model="refundAmount" label="Refund amount" :max="2000" :step="50" prefix-unit="$" disabled />
```
::

### Name

Use the `name` prop to send the range with a form. Both ends are sent under `name[]`, start first, which frameworks like Laravel read as an array. The slider also goes back to its first range when the form is reset.

```vue
<form>
  <KRangeSlider v-model="transactionAmount" name="amount" label="Transaction amount" :max="5000" :step="50" />
</form>
```

## Behavior

- Pressing the track moves the thumb closest to the pointer, which then follows the pointer until it is released.
- When both thumbs sit on the same value, the first move of the pointer picks the one to drag: moving left drags the start, moving right drags the end. Stacked thumbs can always be pulled apart, even at `min` or `max`.
- The thumb moved last is drawn above the other one.
- Changes made with the keyboard, the value fields or the reset button slide the thumbs like the [slider](/components/forms/slider#behavior) does.
- When `min` or `max` change, an end left outside the range is brought back into it.

## Keyboard

On a thumb:

| Key | Action |
| --- | --- |
| :kbd{value="→"}, :kbd{value="↑"} | Increases the value of the thumb by one step. |
| :kbd{value="←"}, :kbd{value="↓"} | Decreases the value of the thumb by one step. |
| :kbd{value="Shift"} + an arrow, :kbd{value="PageUp"}, :kbd{value="PageDown"} | Moves the thumb by ten steps. |
| :kbd{value="Home"}, :kbd{value="End"} | Moves the thumb as far down or up as it can go: to `min`, `max` or the other thumb. |

In a value field:

| Key | Action |
| --- | --- |
| :kbd{value="↑"}, :kbd{value="↓"} | Increases or decreases the value by one step, or ten with :kbd{value="Shift"}. |
| :kbd{value="Home"}, :kbd{value="End"} | Sets the value as low or as high as its end allows. |
| :kbd{value="Enter"}, :kbd{value="Esc"} | Leaves the field and applies the typed value. |

## Customization

Use the `ui` prop to change the classes of each part of the slider, and `class` for the root element. The parts are the same as the [slider](/components/forms/slider#customization)'s, plus `valueSeparator` for the dash between the values.

::code-preview
:::div{class="w-75"}
::::k-range-slider{label="Transaction amount" :min="0" :max="5000" :step="50" prefix-unit="$" :model-value="[500, 2000]" :ui='{"track": "h-1.5 rounded-full", "range": "rounded-full", "valueSeparator": "text-muted"}'}
::::
:::

#code
```vue
<KRangeSlider
  v-model="transactionAmount"
  label="Transaction amount"
  :max="5000"
  :step="50"
  prefix-unit="$"
  :ui="{ track: 'h-1.5 rounded-full', range: 'rounded-full', valueSeparator: 'text-muted' }"
/>
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `modelValue` | `SliderRange` | `[min, max]` |
| `label` | `string` | |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `step` | `number` | `1` |
| `minRange` | `number` | `0` |
| `resetValue` | `SliderRange` | |
| `resetLabel` | `string` | `'Reset to default'` |
| `startLabel` | `string` | `'Minimum'` |
| `endLabel` | `string` | `'Maximum'` |
| `unit` | `string` | |
| `prefixUnit` | `string` | |
| `marks` | `SliderMark[]` | |
| `trackColor` | `string` | |
| `rangeColor` | `string` | |
| `name` | `string` | |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, header?, label?, reset?, resetButton?, value?, valueInput?, valueSeparator?, unit?, container?, control?, track?, range?, thumbAnchor?, thumb?, marks?, mark?, markLabel? }` | |
| `class` | `string` | |

`SliderRange` is `[start: number, end: number]`, and `SliderMark` is described on the [slider page](/components/forms/slider#slidermark).

### Slots

| Slot | Description |
| --- | --- |
| `label` | Replaces the `label` prop. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `SliderRange` |
| `focus` | `FocusEvent`, when a value field or a thumb gets the focus |
| `blur` | `FocusEvent`, when a value field or a thumb loses the focus |
