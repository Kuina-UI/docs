---
title: Radio group
description: A set of options where only one can be chosen, like a plan or a frequency.
---

## Usage

Use the `v-model` directive to control the selected value, and the `options` prop to list the choices.

::code-preview
:::k-radio-group{label="Notification frequency" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}, {"value": "monthly", "label": "Monthly"}]' model-value="weekly"}
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const notificationFrequency = ref('weekly')

const frequencyOptions = [
  { value: 'daily', label: 'Daily' },
  { value: 'weekly', label: 'Weekly' },
  { value: 'monthly', label: 'Monthly' },
]
</script>

<template>
  <KRadioGroup v-model="notificationFrequency" label="Notification frequency" :options="frequencyOptions" />
</template>
```
::

### Options

Each option has a `value` and a `label`. Add a `description` to explain it, and `disabled` to make it unavailable.

::code-preview
:::k-radio-group{label="Plan" direction="col" model-value="plus" :options='[{"value": "free", "label": "Free", "description": "2 linked accounts · Monthly reports · $0"}, {"value": "plus", "label": "Plus", "description": "Unlimited accounts · Budgets and goals · $4.99/month"}, {"value": "business", "label": "Business", "description": "Team access · Priority support · Custom pricing", "disabled": true}]'}
:::

#code
```vue
<script setup lang="ts">
const planOptions = [
  { value: 'free', label: 'Free', description: '2 linked accounts · Monthly reports · $0' },
  { value: 'plus', label: 'Plus', description: 'Unlimited accounts · Budgets and goals · $4.99/month' },
  { value: 'business', label: 'Business', description: 'Team access · Priority support · Custom pricing', disabled: true },
]
</script>

<template>
  <KRadioGroup v-model="plan" label="Plan" direction="col" :options="planOptions" />
</template>
```
::

### Direction

Use the `direction` prop to lay out the options in a row (`row`, default) or in a column (`col`).

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-radio-group{label="Row" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}, {"value": "monthly", "label": "Monthly"}]' model-value="daily"}
::::

::::k-radio-group{label="Column" direction="col" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}, {"value": "monthly", "label": "Monthly"}]' model-value="daily"}
::::
:::

#code
```vue
<KRadioGroup v-model="frequency" label="Row" :options="frequencyOptions" />
<KRadioGroup v-model="frequency" label="Column" direction="col" :options="frequencyOptions" />
```
::

### Variant

Use the `variant` prop to show each option as a card (`card`) instead of a simple radio (`default`).

::code-preview
:::div{class="flex w-full flex-col gap-6"}
::::k-radio-group{label="Billing period" variant="card" model-value="yearly" :options='[{"value": "monthly", "label": "Monthly", "description": "$4.99 billed every month"}, {"value": "yearly", "label": "Yearly", "description": "$47.90 billed every year, 2 months free"}, {"value": "lifetime", "label": "Lifetime", "description": "$149 once, every future update included"}]'}
::::

::::k-radio-group{label="Transfer from" variant="card" direction="col" model-value="checking" :options='[{"value": "checking", "label": "Checking ···· 4821", "description": "Main account, available instantly"}, {"value": "savings", "label": "Savings ···· 0937", "description": "Available in 1 to 2 business days"}]'}
::::
:::

#code
```vue
<KRadioGroup v-model="billingPeriod" label="Billing period" variant="card" :options="billingPeriodOptions" />
<KRadioGroup v-model="sourceAccount" label="Transfer from" variant="card" direction="col" :options="accountOptions" />
```
::

### Color

Use the `color` prop to change the background of the selected radio: `primary`, `secondary` or `neutral` (default). It also takes any CSS color, see [With a custom color](#with-a-custom-color).

::code-preview
:::div{class="flex w-full flex-col gap-6"}
::::k-radio-group{label="Primary" color="primary" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}]' model-value="daily"}
::::

::::k-radio-group{label="Secondary" color="secondary" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}]' model-value="daily"}
::::

::::k-radio-group{label="Neutral" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}]' model-value="daily"}
::::
:::

#code
```vue
<KRadioGroup v-model="frequency" label="Primary" color="primary" :options="frequencyOptions" />
<KRadioGroup v-model="frequency" label="Secondary" color="secondary" :options="frequencyOptions" />
<KRadioGroup v-model="frequency" label="Neutral" :options="frequencyOptions" />
```
::

### Hide label

Set `hide-label` to hide the label from view when the context already makes it clear. Screen readers still announce it.

::code-preview
:::k-radio-group{label="Notification frequency" hide-label :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}, {"value": "monthly", "label": "Monthly"}]' model-value="weekly"}
:::

#code
```vue
<KRadioGroup v-model="notificationFrequency" label="Notification frequency" hide-label :options="frequencyOptions" />
```
::

### Disabled

Use the `disabled` prop to disable the whole group.

::code-preview
:::k-radio-group{label="Statement language" direction="col" disabled :options='[{"value": "english", "label": "English"}, {"value": "french", "label": "French"}]' model-value="english"}
:::

#code
```vue
<KRadioGroup v-model="statementLanguage" label="Statement language" direction="col" disabled :options="languageOptions" />
```
::

### Error message

Use the `error-message` prop to show an error below the options. It turns the radios red and sets `aria-invalid` on the group.

::code-preview
:::k-radio-group{label="Export format" direction="col" error-message="Choose a format to export your transactions." :options='[{"value": "csv", "label": "CSV"}, {"value": "pdf", "label": "PDF"}]'}
:::

#code
```vue
<KRadioGroup
  v-model="exportFormat"
  label="Export format"
  direction="col"
  error-message="Choose a format to export your transactions."
  :options="exportFormatOptions"
/>
```
::

## Examples

### With a custom color

Pass any CSS color to the `color` prop, like a hex code. Use `light-dark()` to set one color for the light theme and another for the dark theme.

::code-preview
:::div{class="flex w-full flex-col gap-6"}
::::k-radio-group{label="Sky blue" color="#0ea5e9" :options='[{"value": "daily", "label": "Daily"}, {"value": "weekly", "label": "Weekly"}]' model-value="daily"}
::::

::::k-radio-group{label="Amber in light theme, lime in dark theme" color="light-dark(#d97706, #a3e635)" variant="card" :options='[{"value": "monthly", "label": "Monthly", "description": "$4.99 billed every month"}, {"value": "yearly", "label": "Yearly", "description": "$47.90 billed every year"}]' model-value="yearly"}
::::
:::

#code
```vue
<KRadioGroup v-model="frequency" label="Sky blue" color="#0ea5e9" :options="frequencyOptions" />
<KRadioGroup
  v-model="billingPeriod"
  label="Amber in light theme, lime in dark theme"
  color="light-dark(#d97706, #a3e635)"
  variant="card"
  :options="billingPeriodOptions"
/>
```
::
