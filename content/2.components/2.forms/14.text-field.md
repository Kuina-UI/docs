---
title: Text field
description: A text input with a floating label, for short values like a name, an email address or an amount.
---

## Usage

Use the `v-model` directive to control the value of the text field.

::code-preview
:::div{class="w-full"}
::::k-text-field{label="Full name" model-value="Avery Collins"}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const fullName = ref('Avery Collins')
</script>

<template>
  <KTextField v-model="fullName" label="Full name" />
</template>
```
::

### Label

Use the `label` prop to name the field. The label sits inside the field while it is empty, and moves up onto the border on focus or once the field has a value.

::code-preview
:::div{class="w-full"}
::::k-text-field{label="Email address" type="email"}
::::
:::

#code
```vue
<KTextField label="Email address" type="email" />
```
::

### Float label

Set `float-label` to `always` to keep the label on the border at all times, with no animation. The field can then show a `placeholder`, which only appears in this mode.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-text-field{label="Full name" float-label="always"}
::::

::::k-text-field{label="Email address" type="email" placeholder="name@company.com" float-label="always"}
::::
:::

#code
```vue
<KTextField label="Full name" float-label="always" />
<KTextField label="Email address" type="email" placeholder="name@company.com" float-label="always" />
```
::

### Type

Use the `type` prop to change the type of the input. Defaults to `text`.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-text-field{label="Email address" type="email" model-value="avery.collins@example.com"}
::::

::::k-text-field{label="Password" type="password" model-value="kuina-2026"}
::::
:::

#code
```vue
<KTextField label="Email address" type="email" />
<KTextField label="Password" type="password" />
```
::

### Mask

Use the `mask` prop to format what is typed, like a card number, a phone number or a time. In the pattern, `#` stands for a digit, `@` for a letter and `*` for either; every other character is written as it is, and added while typing.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-text-field{label="Card number" mask="#### #### #### ####" inputmode="numeric"}
::::

::::k-text-field{label="Phone" mask="+261 ## ## ### ##" inputmode="tel"}
::::
:::

#code
```vue
<KTextField v-model="cardNumber" label="Card number" mask="#### #### #### ####" inputmode="numeric" />
<KTextField v-model="phone" label="Phone" mask="+261 ## ## ### ##" inputmode="tel" />
```
::

`v-model` gets the value as shown, like `+261 34 12 345 67`. Use `v-model:unmasked` to get only the typed characters, like `341234567`, for example to send them to an API.

```vue
<KTextField v-model:unmasked="phoneDigits" label="Phone" mask="+261 ## ## ### ##" inputmode="tel" />
```

The `mask` prop takes everything [useMask](/composables/use-mask) takes: your own tokens, several patterns, `eager` and `preprocess`.

Use the `variant` prop to change the look of the text field: `outline` (default) or `soft`.

::::k-text-field{label="Outline" variant="outline"}
::::

::::k-text-field{label="Soft" variant="soft"}
::::
:::

#code
```vue
<KTextField label="Outline" variant="outline" />
<KTextField label="Soft" variant="soft" />
```
::

::::k-text-field{label="3xl" size="3xl"}

<KTextField label="md" size="md" />
<KTextField label="2xl" size="2xl" />

### Pill

Text fields are pills by default. Set `pill` to `false` to get rounded corners that follow the size.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-text-field{label="Pill"}
::::

::::k-text-field{label="Rounded" :pill="false"}
::::
:::

#code
```vue
<KTextField label="Pill" />
<KTextField label="Rounded" :pill="false" />
```
::

### Icon

Use the `leading-icon` and `trailing-icon` props to show an icon at the start or the end of the field. They take a [Lucide](https://lucide.dev/guide/packages/lucide-vue-next) icon component.

::code-preview
:text-field-icons-example

#code
```vue
<script setup lang="ts">
import { Banknote, Calendar, Search } from 'lucide-vue-next'
</script>

<template>
  <KTextField label="Search transactions" type="search" :leading-icon="Search" />
  <KTextField label="Amount" inputmode="decimal" :leading-icon="Banknote" />
  <KTextField label="Due date" :trailing-icon="Calendar" />
</template>
```
::

### Hint

Use the `hint` prop to show a help text below the field. It is linked to the input with `aria-describedby`.

::code-preview
:::div{class="w-full"}
::::k-text-field{label="Password" type="password" hint="At least 8 characters, including a number."}
::::
:::

#code
```vue
<KTextField label="Password" type="password" hint="At least 8 characters, including a number." />
```
::

### Error message

Use the `error-message` prop to show an error below the field. It replaces the hint, turns the field red and sets `aria-invalid`. Use the `invalid` prop to mark the field as invalid without a message.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-text-field{label="Email address" type="email" model-value="avery.collins@" error-message="Enter a valid email address."}
::::

::::k-text-field{label="Email address" type="email" model-value="avery.collins@" invalid}
::::
:::

#code
```vue
<KTextField label="Email address" type="email" error-message="Enter a valid email address." />
<KTextField label="Email address" type="email" invalid />
```
::

## Examples

### With password toggle

Set `trailing-icon-label` to turn the trailing icon into a button, and listen to `trailing-icon-click` to show or hide the password.

::code-preview
:text-field-password-example

#code
```vue
<script setup lang="ts">
import { Eye, EyeOff } from 'lucide-vue-next'
import { ref } from 'vue'

const password = ref('')
const isPasswordVisible = ref(false)
</script>

<template>
  <KTextField
    v-model="password"
    label="Password"
    autocomplete="current-password"
    :type="isPasswordVisible ? 'text' : 'password'"
    :trailing-icon="isPasswordVisible ? EyeOff : Eye"
    :trailing-icon-label="isPasswordVisible ? 'Hide password' : 'Show password'"
    @trailing-icon-click="isPasswordVisible = !isPasswordVisible"
  />
</template>
```
::

### With trailing action

Set `trailing-action-label` to add an action at the end of the field. It is a button that emits `trailing-action-click`, or a link when `trailing-action-href` is set.

::code-preview
:::div{class="w-full"}
::::k-text-field{label="Email address" type="email" model-value="avery.collins@example.com" readonly trailing-action-label="Edit"}
::::
:::

#code
```vue
<KTextField
  v-model="email"
  label="Email address"
  type="email"
  readonly
  trailing-action-label="Edit"
  @trailing-action-click="startEditingEmail"
/>
```
::

### On a card

The floating label covers the border with the `canvas` color on its top half, to blend with the page background. On another surface, like a card, change that color with the `ui` prop.

::code-preview
:::div{class="w-full rounded-xl border border-line bg-widget p-6"}
::::k-text-field{label="Full name" model-value="Avery Collins" :ui='{"label": "from-widget"}'}
::::
:::

#code
```vue
<KTextField v-model="fullName" label="Full name" :ui="{ label: 'from-widget' }" />
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | |
| `modelValue` | `string` | |
| `id` | `string` | `useId()` |
| `type` | `'text' \| 'email' \| 'password' \| 'search' \| 'tel' \| 'url' \| 'number'` | `'text'` |
| `placeholder` | `string` | |
| `mask` | `string \| string[] \| MaskSettings`, see [useMask](/composables/use-mask#mask-options) | |
| `unmasked` | `string`, with `v-model:unmasked` | |
| `variant` | `'outline' \| 'soft'` | `'outline'` |
| `size` | `'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl'` | `'4xl'` |
| `pill` | `boolean` | `true` |
| `floatLabel` | `'auto' \| 'always'` | `'auto'` |
| `leadingIcon` | `Component` | |
| `trailingIcon` | `Component` | |
| `trailingIconLabel` | `string` | |
| `trailingActionLabel` | `string` | |
| `trailingActionHref` | `string` | |
| `hint` | `string` | |
| `errorMessage` | `string` | |
| `invalid` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, container?, base?, label?, leadingIcon?, trailingIcon?, trailingIconButton?, trailingAction?, hint?, errorMessage?, errorIcon? }` | |
| `class` | `string` | |

Other attributes, like `name`, `autocomplete`, `inputmode`, `maxlength` or `readonly`, and listeners like `@blur` go to the `<input>`.

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `string` |
| `update:unmasked` | `string`, with `mask` |
| `trailingIconClick` | `MouseEvent` |
| `trailingActionClick` | `MouseEvent` |
