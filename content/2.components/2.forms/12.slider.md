---
title: Slider
description: Fine-tune a value within a set range, by dragging the thumb, with the keyboard or by typing it.
---

## Usage

Use the `v-model` directive to control the value, and the `min`, `max` and `step` props to set the range. They default to `0`, `100` and `1`. Without a value, the slider starts at `min`.

::code-preview
:::div{class="w-75"}
::::k-slider{label="Request timeout" :min="0" :max="2000" :step="10" unit="ms" :model-value="1000"}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const requestTimeout = ref(1000)
</script>

<template>
  <KSlider v-model="requestTimeout" label="Request timeout" :min="0" :max="2000" :step="10" unit="ms" />
</template>
```
::

The value is also shown in a small field next to the label. Click it to type a value: the thumb follows 250ms after you stop typing, and the value is rounded and kept in the range when the field loses the focus.

To pick a range between two values, use the [range slider](/components/forms/range-slider).

### Label

Use the `label` prop for a plain text label, or the `label` slot for anything else, like a [tooltip](/components/overlays/tooltip) that explains the setting. The label names both the value field and the thumb for screen readers.

::code-preview
:slider-label-slot-example

#code
```vue
<KSlider v-model="cashReserve" :min="0" :max="10000" :step="100" :reset-value="2500" prefix-unit="$">
  <template #label>
    <KTooltip label="Cash reserve" content="Money kept aside for unexpected expenses." />
  </template>
</KSlider>
```
::

### Units

Use the `unit` prop to show a unit after the value, and `prefixUnit` to show one before it.

::code-preview
:::div{class="flex flex-wrap gap-x-12 gap-y-8"}
::::k-slider{class="w-75" label="Monthly budget" :min="0" :max="5000" :step="50" prefix-unit="$" :model-value="1800"}
::::

::::k-slider{class="w-75" label="Savings rate" :min="0" :max="50" :step="0.5" unit="%" :model-value="12.5"}
::::
:::

#code
```vue
<KSlider v-model="monthlyBudget" label="Monthly budget" :min="0" :max="5000" :step="50" prefix-unit="$" />
<KSlider v-model="savingsRate" label="Savings rate" :min="0" :max="50" :step="0.5" unit="%" />
```
::

### Step

The value field shows as many decimals as the `step`: a step of `0.5` shows `12.5`, a step of `0.25` shows `12.50`. With a whole step, typed decimals are dropped.

::code-preview
:::div{class="w-75"}
::::k-slider{label="Exchange rate margin" :min="0" :max="5" :step="0.25" unit="%" :model-value="1.5"}
::::
:::

#code
```vue
<KSlider v-model="exchangeRateMargin" label="Exchange rate margin" :min="0" :max="5" :step="0.25" unit="%" />
```
::

### Reset value

Use the `resetValue` prop to offer a way back to a default value. A reset button appears next to the value when the pointer is over the slider, or while its value field or thumb has the keyboard focus, as long as the value differs from `resetValue`. Its `resetLabel` defaults to `Reset to default`, and is shown in a tooltip.

::code-preview
:::div{class="w-75"}
::::k-slider{label="Request timeout" :min="0" :max="2000" :step="10" :reset-value="1000" unit="ms" :model-value="1250"}
::::
:::

#code
```vue
<KSlider
  v-model="requestTimeout"
  label="Request timeout"
  :min="0"
  :max="2000"
  :step="10"
  :reset-value="1000"
  unit="ms"
/>
```
::

### Marks

Use the `marks` prop to label values under the track. Each mark has a `value` inside the range and a `label`. Labels that would collide wrap their words, and all of them are hidden when they still don't fit.

::code-preview
:::div{class="flex w-full flex-col gap-y-5"}
::::k-slider{class="w-100 max-w-full" label="Risk tolerance" :min="1" :max="3" :model-value="2" :marks='[{"value": 1, "label": "Conservative"}, {"value": 2, "label": "Moderate growth"}, {"value": 3, "label": "Aggressive"}]'}
::::

::::k-slider{class="w-57.5" label="Risk tolerance" :min="1" :max="3" :model-value="2" :marks='[{"value": 1, "label": "Conservative"}, {"value": 2, "label": "Moderate growth"}, {"value": 3, "label": "Aggressive"}]'}
::::

::::k-slider{class="w-25" label="Risk tolerance" :min="1" :max="3" :model-value="2" :marks='[{"value": 1, "label": "Conservative"}, {"value": 2, "label": "Moderate growth"}, {"value": 3, "label": "Aggressive"}]'}
::::
:::

#code
```vue
<script setup lang="ts">
import type { SliderMark } from '@kuina-ui/vue'

const riskToleranceMarks: SliderMark[] = [
  { value: 1, label: 'Conservative' },
  { value: 2, label: 'Moderate growth' },
  { value: 3, label: 'Aggressive' },
]
</script>

<template>
  <KSlider v-model="riskTolerance" label="Risk tolerance" :min="1" :max="3" :marks="riskToleranceMarks" />
</template>
```
::

A mark outside the range, or two marks with the same value, throw an error.

### Colors

Use the `trackColor` and `rangeColor` props to change the color of the track and of the filled part before the thumb, which also colors the thumb ring. They accept any CSS color.

::code-preview
:::div{class="w-100 max-w-full"}
::::k-slider{label="Risk level" :min="1" :max="5" :model-value="3" track-color="light-dark(var(--color-green-500), var(--color-green-600))" range-color="light-dark(var(--color-red-500), var(--color-red-600))" :marks='[{"value": 1, "label": "1"}, {"value": 2, "label": "2"}, {"value": 3, "label": "3"}, {"value": 4, "label": "4"}, {"value": 5, "label": "5"}]'}
::::
:::

#code
```vue
<KSlider
  v-model="riskLevel"
  label="Risk level"
  :min="1"
  :max="5"
  :marks="riskLevelMarks"
  track-color="light-dark(var(--color-green-500), var(--color-green-600))"
  range-color="light-dark(var(--color-red-500), var(--color-red-600))"
/>
```
::

### Name

Use the `name` prop to send the value with a form. The slider also goes back to its first value when the form is reset.

```vue
<form>
  <KSlider v-model="requestTimeout" name="request-timeout" label="Request timeout" :max="2000" :step="10" />
</form>
```

## Behavior

- Pressing the track moves the thumb to the nearest step under the pointer, and the thumb follows the pointer until it is released.
- Changes made with the keyboard, the value field or the reset button slide the thumb: the farther it goes, the longer it takes, from 100ms to 300ms for the whole track. It follows the pointer without delay while dragged.
- While you type in the value field, outside changes to the value don't rewrite what you typed.
- When `min` or `max` change, a value left outside the range is brought back into it.

## Keyboard

On the thumb:

| Key | Action |
| --- | --- |
| :kbd{value="→"}, :kbd{value="↑"} | Increases the value by one step. |
| :kbd{value="←"}, :kbd{value="↓"} | Decreases the value by one step. |
| :kbd{value="Shift"} + an arrow, :kbd{value="PageUp"}, :kbd{value="PageDown"} | Moves by ten steps. |
| :kbd{value="Home"}, :kbd{value="End"} | Moves to `min` or `max`. |

In the value field:

| Key | Action |
| --- | --- |
| :kbd{value="↑"}, :kbd{value="↓"} | Increases or decreases the value by one step, or ten with :kbd{value="Shift"}. |
| :kbd{value="Home"}, :kbd{value="End"} | Sets the value to `min` or `max`. |
| :kbd{value="Enter"}, :kbd{value="Esc"} | Leaves the field and applies the typed value. |

## Customization

Use the `ui` prop to change the classes of each part of the slider, and `class` for the root element. Your classes always win: `h-1.5` replaces the default `h-1` of the track instead of being added to it.

::code-preview
:::div{class="w-75"}
::::k-slider{label="Request timeout" :min="0" :max="2000" :step="10" unit="ms" :model-value="1000" :ui='{"track": "h-1.5 rounded-full", "range": "rounded-full"}'}
::::
:::

#code
```vue
<KSlider
  v-model="requestTimeout"
  label="Request timeout"
  :max="2000"
  :step="10"
  unit="ms"
  :ui="{ track: 'h-1.5 rounded-full', range: 'rounded-full' }"
/>
```
::

| --- | --- | --- |

| `label` | `string` | |

| `max` | `number` | `100` |
| `step` | `number` | `1` |
| `resetValue` | `number` | |
| `resetLabel` | `string` | `'Reset to default'` |
| `unit` | `string` | |
| `prefixUnit` | `string` | |
| `marks` | `SliderMark[]` | |
| `trackColor` | `string` | |
| `rangeColor` | `string` | |
| `name` | `string` | |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, header?, label?, reset?, resetButton?, value?, valueInput?, unit?, container?, control?, track?, range?, thumbAnchor?, thumb?, marks?, mark?, markLabel? }` | |
| `class` | `string` | |

### SliderMark

| Property | Type |
| --- | --- |
| `value` | `number` |
| `label` | `string` |

### Slots

| Slot | Description |
| --- | --- |
| `label` | Replaces the `label` prop. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `number` |
| `focus` | `FocusEvent`, when the value field or the thumb gets the focus |
| `blur` | `FocusEvent`, when the value field or the thumb loses the focus |
