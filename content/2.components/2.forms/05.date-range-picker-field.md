---
title: Date range picker field
description: A date range picker with a floating label, a hint and an error message, made for forms.
---

## Usage

Use the `v-model` directive to control the selected range, a `[start, end]` pair of `YYYY-MM-DD` strings. The date range picker field opens the same two months as the [Date range picker](/components/forms/date-range-picker), with the same shortcuts, and has the label, hint and error message of the [Date picker field](/components/forms/date-picker-field).

::code-preview
:::div{class="w-full"}
::::k-date-range-picker-field{label="Report period" :model-value='["2026-11-03", "2026-11-16"]'}
::::
:::

#code
```vue
<script setup lang="ts">
import type { DateRange } from '@kuina-ui/vue'
import { ref } from 'vue'

const reportPeriod = ref<DateRange>(['2026-11-03', '2026-11-16'])
</script>

<template>
  <KDateRangePickerField v-model="reportPeriod" label="Report period" />
</template>
```
::

### Label, hint and error message

The label floats onto the border once a range is selected, like on the [Date picker field](/components/forms/date-picker-field#label). Use `float-label`, `placeholder`, `hint`, `error-message` and `invalid` the same way.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-date-range-picker-field{label="Report period" hint="Reports cover at most 90 days."}
::::

::::k-date-range-picker-field{label="Report period" error-message="Choose the end of the period."}
::::
:::

#code
```vue
<KDateRangePickerField v-model="reportPeriod" label="Report period" hint="Reports cover at most 90 days." />
<KDateRangePickerField v-model="reportPeriod" label="Report period" error-message="Choose the end of the period." />
```
::

### Ranges

The date range picker field takes the same range props as the [Date range picker](/components/forms/date-range-picker#shortcuts): `shortcuts`, `max-range-days`, `min`, `max`, `disabled-dates`, `is-date-disabled` and `selection-label`.

::code-preview
:::div{class="w-full"}
::::k-date-range-picker-field{label="Export period" :max-range-days="7"}
::::
:::

#code
```vue
<KDateRangePickerField v-model="exportPeriod" label="Export period" :max-range-days="7" :shortcuts="reportShortcuts" />
```
::

### Typing

Set `editable` to type the range in the field, the dash coming by itself after the start, like on the [Date range picker](/components/forms/date-range-picker#typing).

::code-preview
:::div{class="w-full"}
::::k-date-range-picker-field{label="Trip dates" editable}
::::
:::

#code
```vue
<KDateRangePickerField v-model="tripDates" label="Trip dates" editable />
```
::

### Forms

Use the `name` prop to send the range with a `<form>`: the field adds two hidden inputs with that name, the start date then the end date.

```vue
<form action="/reports" method="post">
  <KDateRangePickerField v-model="reportPeriod" name="period" label="Report period" />
</form>
```

## API

### Props

The date range picker field has every prop of the [Date picker field](/components/forms/date-picker-field#props), with the range props of the [Date range picker](/components/forms/date-range-picker#props): `modelValue` is a `DateRange`, and it adds `shortcuts`, `maxRangeDays` and a `selectionLabel(selectedRange, activeShortcut)`. Its `ui` also takes `shortcuts`, `shortcutLabel` and `shortcutCheckIcon`.

### Slots

| Slot | Props | Description |
| --- | --- | --- |
| `selection` | `{ selectedRange, activeShortcut }` | Replaces the selected range shown in the field. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `DateRange \| undefined` |
| `update:open` | `boolean` |
