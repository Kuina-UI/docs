---
title: Segmented control
description: A row of options where only one can be chosen, with a thumb that slides to the selected one.
---

## Usage

Use the `v-model` directive to control the selected value, and the `options` prop to list the choices. The `aria-label` names the control for screen readers.

::code-preview
:::k-segmented-control{aria-label="Transaction type" :options='[{"value": "all", "label": "All"}, {"value": "income", "label": "Income"}, {"value": "expenses", "label": "Expenses"}]' model-value="all"}
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const transactionType = ref('all')

const transactionTypeOptions = [
  { value: 'all', label: 'All' },
  { value: 'income', label: 'Income' },
  { value: 'expenses', label: 'Expenses' },
]
</script>

<template>
  <KSegmentedControl v-model="transactionType" aria-label="Transaction type" :options="transactionTypeOptions" />
</template>
```
::

### Options

Each option has a `value` and a `label`. Add an `icon` to show it before the label, and `disabled` to make it unavailable.

::code-preview
:::k-segmented-control{aria-label="Billing cycle" model-value="yearly" :options='[{"value": "monthly", "label": "Monthly"}, {"value": "yearly", "label": "Yearly"}, {"value": "lifetime", "label": "Lifetime", "disabled": true}]'}
:::

#code
```vue
<script setup lang="ts">
const billingCycleOptions = [
  { value: 'monthly', label: 'Monthly' },
  { value: 'yearly', label: 'Yearly' },
  { value: 'lifetime', label: 'Lifetime', disabled: true },
]
</script>

<template>
  <KSegmentedControl v-model="billingCycle" aria-label="Billing cycle" :options="billingCycleOptions" />
</template>
```
::

### Pill

Set `:pill="false"` to use rounded corners instead of the default pill shape.

::code-preview
:::k-segmented-control{aria-label="Transaction type" :pill="false" :options='[{"value": "all", "label": "All"}, {"value": "income", "label": "Income"}, {"value": "expenses", "label": "Expenses"}]' model-value="all"}
:::

#code
```vue
<KSegmentedControl
  v-model="transactionType"
  aria-label="Transaction type"
  :pill="false"
  :options="transactionTypeOptions"
/>
```
::

### Icons and square

Pass any Vue component as the `icon` of an option, like a [Lucide](https://lucide.dev) icon. Use the `square` prop to show only the icons: each `label` becomes the accessible name of its option.

::code-preview
:segmented-control-icons-example

#code
```vue
<script setup lang="ts">
import { ChartLine, LayoutGrid, List, Table2 } from 'lucide-vue-next'

const reportViewOptions = [
  { value: 'chart', label: 'Chart', icon: ChartLine },
  { value: 'table', label: 'Table', icon: Table2 },
]

const accountLayoutOptions = [
  { value: 'list', label: 'List view', icon: List },
  { value: 'grid', label: 'Grid view', icon: LayoutGrid },
]
</script>

<template>
  <KSegmentedControl v-model="reportView" aria-label="Report view" :options="reportViewOptions" />
  <KSegmentedControl v-model="accountLayout" aria-label="Account layout" square :options="accountLayoutOptions" />
  <KSegmentedControl
    v-model="accountLayout"
    aria-label="Account layout"
    square
    :pill="false"
    :options="accountLayoutOptions"
  />
</template>
```
::

### Block

Use the `block` prop to fill the width of the container, with options of equal width.

::code-preview
:::k-segmented-control{aria-label="Spending period" block :options='[{"value": "day", "label": "Day"}, {"value": "week", "label": "Week"}, {"value": "month", "label": "Month"}, {"value": "year", "label": "Year"}]' model-value="month"}
:::

#code
```vue
<KSegmentedControl v-model="spendingPeriod" aria-label="Spending period" block :options="periodOptions" />
```
::

### Disabled

Use the `disabled` prop to disable the whole control.

::code-preview
:::k-segmented-control{aria-label="Transaction type" disabled :options='[{"value": "all", "label": "All"}, {"value": "income", "label": "Income"}, {"value": "expenses", "label": "Expenses"}]' model-value="income"}
:::

#code
```vue
<KSegmentedControl v-model="transactionType" aria-label="Transaction type" disabled :options="transactionTypeOptions" />
```

## Examples

### Many options

When the options are wider than their container, the control scrolls horizontally. The selected option is scrolled into view when the page loads, and again whenever another option close to an edge is selected.

::code-preview
:::div{class="max-w-xs"}
::::k-segmented-control{aria-label="Statement month" model-value="november" :options='[{"value": "january", "label": "January"}, {"value": "february", "label": "February"}, {"value": "march", "label": "March"}, {"value": "april", "label": "April"}, {"value": "may", "label": "May"}, {"value": "june", "label": "June"}, {"value": "july", "label": "July"}, {"value": "august", "label": "August"}, {"value": "september", "label": "September"}, {"value": "october", "label": "October"}, {"value": "november", "label": "November"}, {"value": "december", "label": "December"}]'}
::::
:::

#code
```vue
<div class="max-w-xs">
  <KSegmentedControl v-model="statementMonth" aria-label="Statement month" :options="monthOptions" />
</div>
```
::

## Customization

Use the `ui` prop to change the classes of each part of the control, and `class` for the root element. Your classes always win: `rounded-none` replaces the default `rounded-full` instead of being added to it.

::code-preview
:::k-segmented-control{aria-label="Transaction type" :ui='{"root": "rounded-none", "thumb": "rounded-none", "option": "rounded-none"}' :options='[{"value": "all", "label": "All"}, {"value": "income", "label": "Income"}, {"value": "expenses", "label": "Expenses"}]' model-value="all"}
:::

#code
```vue
<KSegmentedControl
  v-model="transactionType"
  aria-label="Transaction type"
  :ui="{ root: 'rounded-none', thumb: 'rounded-none', option: 'rounded-none' }"
  :options="transactionTypeOptions"
/>
```
::

| Prop | Type | Default |
| --- | --- | --- |
| `ariaLabel` | `string` | |
| `options` | `SegmentedControlOption[]` | |
| `modelValue` | `string` | |
| `name` | `string` | `useId()` |

| `disabled` | `boolean` | `false` |

| `class` | `string` | |
