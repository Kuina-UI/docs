---
title: Switch
description: A toggle that turns a setting on or off right away.
---

## Usage

Use the `v-model` directive to control whether the switch is on.

::code-preview
:::k-switch{label="Two-factor authentication" :model-value="true"}
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const hasTwoFactorAuthentication = ref(true)
</script>

<template>
  <KSwitch v-model="hasTwoFactorAuthentication" label="Two-factor authentication" />
</template>
```
::

### Label

Use the `label` prop to set the text next to the switch. Without a visible label, set `aria-label` so screen readers can still name the switch.

::code-preview
:::div{class="flex flex-wrap items-start gap-x-8 gap-y-4"}
::::k-switch{label="Weekly summary"}
::::

::::k-switch{aria-label="Hide balances"}
::::
:::

#code
```vue
<KSwitch v-model="sendsWeeklySummary" label="Weekly summary" />
<KSwitch v-model="hidesBalances" aria-label="Hide balances" />
```
::

### Description

Use the `description` prop to explain the setting below the label. It is linked to the switch with `aria-describedby`.

::code-preview
:::k-switch{label="Large transaction alerts" description="Get notified when a payment goes over $500."}
:::

#code
```vue
<KSwitch
  v-model="sendsLargeTransactionAlerts"
  label="Large transaction alerts"
  description="Get notified when a payment goes over $500."
/>
```
::

### Label position

Use the `label-position` prop to put the label before the switch (`start`) or after it (`end`, default).

::code-preview
:::div{class="flex flex-wrap items-start gap-x-8 gap-y-4"}
::::k-switch{label="Show cents" label-position="start" :model-value="true"}
::::

::::k-switch{label="Show cents" :model-value="true"}
::::
:::

#code
```vue
<KSwitch v-model="showsCents" label="Show cents" label-position="start" />
<KSwitch v-model="showsCents" label="Show cents" />
```
::

### Block

Set `block` to make the switch fill the width of its container, with the label and the switch at both ends. It suits lists of settings.

::code-preview
:::div{class="flex w-full max-w-md flex-col divide-y divide-line"}
::::div{class="pb-4"}
:::::k-switch{label="Email notifications" description="A summary of your spending every Monday morning." label-position="start" block :model-value="true"}
:::::
::::

::::div{class="pt-4"}
:::::k-switch{label="Round-up savings" description="Round card payments up to the nearest dollar and move the change to savings." label-position="start" block}
:::::
::::
:::

#code
```vue
<KSwitch
  v-model="sendsEmailNotifications"
  label="Email notifications"
  description="A summary of your spending every Monday morning."
  label-position="start"
  block
/>
```
::

### Color

Use the `color` prop to change the background of the switch once it is on: `primary`, `secondary` or `neutral` (default). It also takes any CSS color, see [With a custom color](#with-a-custom-color).

::code-preview
:::div{class="flex flex-wrap items-start gap-x-8 gap-y-4"}
::::k-switch{label="Primary" color="primary" :model-value="true"}
::::

::::k-switch{label="Secondary" color="secondary" :model-value="true"}
::::

::::k-switch{label="Neutral" :model-value="true"}
::::
:::

#code
```vue
<KSwitch v-model="isPrimaryOn" label="Primary" color="primary" />
<KSwitch v-model="isSecondaryOn" label="Secondary" color="secondary" />
<KSwitch v-model="isNeutralOn" label="Neutral" />
```
::

### Disabled

Use the `disabled` prop to disable the switch.

::code-preview
:::div{class="flex flex-wrap items-start gap-x-8 gap-y-4"}
::::k-switch{label="Biometric login" disabled}
::::

::::k-switch{label="Automatic backups" disabled :model-value="true"}
::::
:::

#code
```vue
<KSwitch v-model="usesBiometricLogin" label="Biometric login" disabled />
<KSwitch v-model="hasAutomaticBackups" label="Automatic backups" disabled />
```
::

## Examples

### With a custom color

Pass any CSS color to the `color` prop, like a hex code. Use `light-dark()` to set one color for the light theme and another for the dark theme.

::code-preview
:::div{class="flex flex-wrap items-start gap-x-8 gap-y-4"}
::::k-switch{label="Sky blue" color="#0ea5e9" :model-value="true"}
::::

::::k-switch{label="Amber in light theme, lime in dark theme" color="light-dark(#d97706, #a3e635)" :model-value="true"}
::::
:::

#code
```vue
<KSwitch v-model="isSkyBlueOn" label="Sky blue" color="#0ea5e9" />
<KSwitch
  v-model="isAmberOrLimeOn"
  label="Amber in light theme, lime in dark theme"
  color="light-dark(#d97706, #a3e635)"
/>
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | |
| `description` | `string` | |
| `modelValue` | `boolean` | `false` |
| `color` | `'primary' \| 'secondary' \| 'neutral' \| string` | `'neutral'` |
| `labelPosition` | `'start' \| 'end'` | `'end'` |
| `block` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, base?, thumb?, wrapper?, label?, description? }` | |
| `class` | `string` | |

Other attributes, like `name` or `aria-label`, go to the `<input>`.

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `boolean` |
