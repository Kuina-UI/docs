## Usage

Use the `v-model` directive to control the selected value, and the `options` prop to list the choices. The select field takes the same options as [Select](/components/forms/select), and lines up with a [Text field](/components/forms/text-field) of the same size.

::code-preview
:::div{class="w-full"}
::::k-select-field{label="Country" model-value="France" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const country = ref('France')
</script>

<template>
  <KSelectField v-model="country" label="Country" :options="['Canada', 'France', 'Germany', 'Japan', 'Madagascar']" />
</template>
```
::

### Label

Use the `label` prop to name the field. The label sits inside the field while it is empty, and moves up onto the border on focus, while the list is open, or once a value is selected.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-select-field{label="Country" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::

::::k-select-field{label="Country" model-value="Japan" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::
:::

#code
```vue
<KSelectField label="Country" :options="countryOptions" />
<KSelectField v-model="country" label="Country" :options="countryOptions" />
```
::

### Placeholder

Use the `placeholder` prop to show a hint inside the empty field. It only shows once the label has moved up, on focus or while the list is open, so the two never cover each other. Click the field below to see it.

::code-preview
:::div{class="w-full"}
::::k-select-field{label="Country" placeholder="Choose your country" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::
:::

#code
```vue
<KSelectField v-model="country" label="Country" placeholder="Choose your country" :options="countryOptions" />
```
::

### Float label

Set `float-label` to `always` to keep the label on the border at all times, with no animation. The placeholder then stays visible while the field is empty.

::code-preview
:::div{class="grid w-full gap-6 sm:grid-cols-2"}
::::k-select-field{label="Country" float-label="always" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::

::::k-select-field{label="Country" placeholder="Choose your country" float-label="always" :options='["Canada", "France", "Germany", "Japan", "Madagascar"]'}
::::
:::

#code
```vue
<KSelectField v-model="country" label="Country" float-label="always" :options="countryOptions" />
<KSelectField v-model="country" label="Country" placeholder="Choose your country" float-label="always" :options="countryOptions" />
```
::

### Search

Add `searchable` to search the options. By default, the search input sits at the top of the list, as in [Select](/components/forms/select#search). Set `search-placement` to `field` to type straight into the field instead: the list opens as you type, and the search input leaves the list.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-select-field{label="Country" model-value="Japan" searchable search-placeholder="Search countries" :options='["Canada", "France", "Germany", "Japan", "Madagascar", "United Kingdom", "United States"]'}
::::

::::k-select-field{label="Country" model-value="Madagascar" searchable search-placement="field" placeholder="Type a country" :options='["Canada", "France", "Germany", "Japan", "Madagascar", "United Kingdom", "United States"]'}
::::
:::

#code
```vue
<KSelectField v-model="country" label="Country" :options="countryOptions" searchable search-placeholder="Search countries" />
<KSelectField v-model="country" label="Country" :options="countryOptions" searchable search-placement="field" placeholder="Type a country" />
```
::

When you search in the field:

- the field keeps showing the selected label, even once the list is open, until you type. The first letter, a paste or :kbd{value="Backspace"} starts a new search, so nothing moves when you click;
- while the search is empty, the selection shows in grey as its placeholder. With nothing selected, it shows `placeholder`, or `search-placeholder` if there is none;
- choosing an option shows its label again. With `multiple`, the list stays open, and the next letter starts a new search;
- :kbd{value="Esc"} or a click outside drops the search and keeps the selection.

### Like the select

Everything about the options and the list works as in [Select](/components/forms/select):

- [options and groups](/components/forms/select#options), with a `description` and `disabled`;
- [option keys](/components/forms/select#option-keys) to pass the objects of your API, and [avatars](/components/forms/select#avatars);
- [multiple selection](/components/forms/select#multiple) and `selection-label`;
- the [clear button](/components/forms/select#clear-button) and [actions](/components/forms/select#actions);
- the [`option`, `selection` and `search` slots](/components/forms/select#custom-content), [forms](/components/forms/select#forms) and [translation](/components/forms/select#translation);
- [side, align, flip and fixed position](/components/forms/select#side-and-align), and `v-model:open`.

The `selection` slot only shows once a value is selected, so it never covers the label.

### Hint

Use the `hint` prop to show a help text below the field. It is linked to the field with `aria-describedby`.

::code-preview
:::div{class="w-full"}
::::k-select-field{label="Default currency" model-value="usd" hint="Used for new accounts and reports." :options='[{"value": "usd", "label": "US dollar (USD)"}, {"value": "eur", "label": "Euro (EUR)"}]'}
::::
:::

#code
```vue
<KSelectField v-model="currency" label="Default currency" hint="Used for new accounts and reports." :options="currencyOptions" />
```
::

### Error message

Use the `error-message` prop to show an error below the field. It replaces the hint, turns the field red and sets `aria-invalid`. Use the `invalid` prop to mark the field as invalid without a message.

::code-preview
:::div{class="grid w-full items-start gap-6 sm:grid-cols-2"}
::::k-select-field{label="Country" error-message="Choose your country of residence." :options='["Canada", "France", "Germany"]'}
::::

::::k-select-field{label="Country" model-value="Germany" invalid :options='["Canada", "France", "Germany"]'}
::::
:::

#code
```vue
<KSelectField v-model="country" label="Country" :options="countryOptions" error-message="Choose your country of residence." />
<KSelectField v-model="country" label="Country" :options="countryOptions" invalid />
```

### Icon and avatar

Use the `leading-icon` prop to show an icon at the start of the field, and `trailing-icon` to replace the arrows at the end, or `null` to remove them. When the selected option has an avatar, the avatar takes the place of the leading icon.

::code-preview
:select-field-icons-example

#code
```vue
<script setup lang="ts">
import type { SelectOption } from '@kuina-ui/vue'
import { Globe, Wallet } from 'lucide-vue-next'

const memberOptions: SelectOption[] = [
  { value: 'avery-collins', label: 'Avery Collins', avatar: '/avatars/avery-collins.webp' },
  { value: 'jordan-reyes', label: 'Jordan Reyes', avatar: '/avatars/jordan-reyes.webp' },
]
</script>

<template>
  <KSelectField v-model="country" label="Country" :options="countryOptions" :leading-icon="Globe" />
  <KSelectField v-model="account" label="Account" :options="accountOptions" :leading-icon="Wallet" />
  <KSelectField v-model="assignee" label="Assignee" :options="memberOptions" clearable />
</template>
```
::

## Examples

### In a form

An approver read from API objects with search, an account with an action and a hint, and several categories at once.

::code-preview
:select-field-form-example

#code
```vue
<script setup lang="ts">
import type { SelectAction } from '@kuina-ui/vue'
import { Plus } from 'lucide-vue-next'
import { ref } from 'vue'

interface TeamMember {
  id: number
  fullName: string
  email: string
  photoUrl: string
}

const teamMembers: TeamMember[] = [
  { id: 1, fullName: 'Avery Collins', email: 'avery.collins@example.com', photoUrl: '/avatars/avery-collins.webp' },
  { id: 2, fullName: 'Jordan Reyes', email: 'jordan.reyes@example.com', photoUrl: '/avatars/jordan-reyes.webp' },
  { id: 3, fullName: 'Riley Brooks', email: 'riley.brooks@example.com', photoUrl: '/avatars/riley-brooks.webp' },
]

const accountActions: SelectAction[] = [{ label: 'Link an account', icon: Plus, onSelect: () => openLinkAccountDialog() }]

const approverId = ref<number>(2)
const account = ref('checking')
const categories = ref(['Dining', 'Travel'])
</script>

<template>
  <KSelectField
    v-model="approverId"
    label="Approver"
    :options="teamMembers"
    value-key="id"
    label-key="fullName"
    description-key="email"
    avatar-key="photoUrl"
    searchable
  />
  <KSelectField
    v-model="account"
    label="Paid from"
    :options="accountOptions"
    :actions="accountActions"
    hint="The account charged for this expense."
  />
  <KSelectField v-model="categories" label="Categories" :options="categoryOptions" multiple clearable />
</template>
```
::

## Keyboard

The keyboard works as in [Select](/components/forms/select#keyboard). When you search in the field, the keys that edit text keep their usual role: letters and :kbd{value="Space"} type, :kbd{value="Home"} and :kbd{value="End"} move the cursor, and :kbd{value="↓"} or :kbd{value="↑"} open the list.

## Customization

Use the `ui` prop to change the classes of each part of the field and of its list, and `class` for the root element. Your classes always win: `rounded-2xl` replaces the default `rounded-xl` of the list instead of being added to it.

::code-preview
:::div{class="w-full"}
::::k-select-field{label="Rounder list" model-value="France" :options='["Canada", "France"]' :ui='{"panel": "rounded-2xl", "option": "rounded-lg"}'}
::::
:::

#code
```vue
<KSelectField label="Rounder list" :options="countryOptions" :ui="{ panel: 'rounded-2xl', option: 'rounded-lg' }" />
```
::
