---
title: Date range picker
description: A button that opens two months side by side to pick a start and an end date, with shortcuts and a maximum length.
---

## Usage

Use the `v-model` directive to control the selected range, a `[start, end]` pair of `YYYY-MM-DD` strings. The `label` prop names the date range picker and its calendar for screen readers.

::code-preview
:::div{class="w-full"}
::::k-date-range-picker{label="Report period" :model-value='["2026-11-03", "2026-11-16"]'}
::::
:::

#code
```vue
<script setup lang="ts">
import type { DateRange } from '@kuina-ui/vue'
import { ref } from 'vue'

const reportPeriod = ref<DateRange>(['2026-11-03', '2026-11-16'])
</script>

<template>
  <KDateRangePicker v-model="reportPeriod" label="Report period" />
</template>
```
::

The first click starts the range and the second one ends it. In between, hovering a day previews the range, and clicking a day before the start moves the start there. The calendar stays open, so you can adjust the range, and closes on a click outside or :kbd{value="Esc"}.

On small screens, the calendar shows one month instead of two.

### Shortcuts

Use the `shortcuts` prop to list ready-made ranges next to the calendar. When the selected range matches a shortcut, the date range picker shows its label. The shortcuts are hidden on small screens.

::code-preview
:date-range-picker-shortcuts-example

#code
```vue
<script setup lang="ts">
import type { DateRange, DateRangeShortcut } from '@kuina-ui/vue'
import { ref } from 'vue'

function findIsoDateDaysAgo(dayCount: number) {
  const pastDate = new Date()
  pastDate.setDate(pastDate.getDate() - dayCount)
  return [pastDate.getFullYear(), pastDate.getMonth() + 1, pastDate.getDate()]
    .map((datePart) => String(datePart).padStart(2, '0'))
    .join('-')
}

const today = findIsoDateDaysAgo(0)

const reportShortcuts: DateRangeShortcut[] = [
  { label: 'Today', value: [today, today] },
  { label: 'Yesterday', value: [findIsoDateDaysAgo(1), findIsoDateDaysAgo(1)] },
  { label: 'Last 7 days', value: [findIsoDateDaysAgo(7), today] },
  { label: 'Last 30 days', value: [findIsoDateDaysAgo(30), today] },
]

const reportPeriod = ref<DateRange>()
</script>

<template>
  <KDateRangePicker v-model="reportPeriod" label="Report period" :shortcuts="reportShortcuts" />
</template>
```
::

### Maximum length

Use the `max-range-days` prop to limit the length of the range, both days included. Once the start is picked, the days too far from it are dimmed.

::code-preview
:::div{class="w-full"}
::::k-date-range-picker{label="Export period" :max-range-days="7"}
::::
:::

#code
```vue
<KDateRangePicker v-model="exportPeriod" label="Export period" :max-range-days="7" />
```
::

### Min and max

Use the `min` and `max` props to limit the dates that can be picked, and `disabled-dates` or `is-date-disabled` to dim more days, like on the [Date picker](/components/forms/date-picker#disabled-dates). A disabled day cannot start or end a range.

::code-preview
:::div{class="w-full"}
::::k-date-range-picker{label="Statement period" :model-value='["2026-11-02", "2026-11-13"]' min="2026-10-27" max="2026-11-26"}
::::
:::

#code
```vue
<KDateRangePicker v-model="statementPeriod" label="Statement period" min="2026-10-27" max="2026-11-26" />
```
::

### Custom selection

The selected range is shown as `11/03/26 – 11/16/26`, a single date when both ends are the same day, or the label of the matching shortcut. Use the `selection-label` prop to write it yourself: it receives the range and the matching shortcut, if any. The `selection` slot receives the same values.

::code-preview
:date-range-picker-selection-example

#code
```vue
<script setup lang="ts">
import type { DateRange, DateRangeShortcut } from '@kuina-ui/vue'

const dayMonthFormat = new Intl.DateTimeFormat('en-US', { month: 'short', day: 'numeric', timeZone: 'UTC' })

function formatTripDates([departureDate, returnDate]: DateRange, activeShortcut?: DateRangeShortcut) {
  if (activeShortcut) return activeShortcut.label

  const nightCount = Math.round((Date.parse(returnDate) - Date.parse(departureDate)) / 86_400_000)
  const [departure, arrival] = [departureDate, returnDate].map((isoDate) =>
    dayMonthFormat.format(new Date(`${isoDate}T00:00:00Z`)),
  )

  return `${departure} – ${arrival} · ${nightCount} nights`
}
</script>

<template>
  <KDateRangePicker v-model="tripDates" label="Trip dates" :selection-label="formatTripDates" />
</template>
```
::

### Forms

Use the `name` prop to send the range with a `<form>`: the date range picker adds two hidden inputs with that name, the start date then the end date.

```vue
<form action="/reports" method="post">
  <KDateRangePicker v-model="reportPeriod" name="period" label="Report period" />
</form>
```

### Translation

The date range picker takes the same texts as the [Date picker](/components/forms/date-picker#translation): `locale` and `week-starts-on` for the dates, `weekday-label`, `month-label` and `day-label` to write them yourself, and a prop for each fixed text. Its `placeholder` defaults to `Select date range...`, and the shortcuts are labeled by you, in your language.

```vue
<KDateRangePicker
  v-model="reportPeriod"
  label="Période"
  locale="fr-FR"
  :week-starts-on="1"
  placeholder="Choisir une période"
  previous-month-label="Mois précédent"
  next-month-label="Mois suivant"
  :shortcuts="[{ label: 'Cette semaine', value: currentWeek }]"
/>
```

### Position and open state

The `side`, `align`, `flip`, `strategy` and `v-model:open` props work like on the [Date picker](/components/forms/date-picker#side-and-align).

## Keyboard

The keys are the same as on the [Date picker](/components/forms/date-picker#keyboard). Moving the focus with the keyboard previews the range like hovering, and :kbd{value="Enter"} or :kbd{value="Space"} picks the start, then the end.

## API

### Props

The date range picker has every prop of the [Date picker](/components/forms/date-picker#props), with these differences.

| Prop | Type | Default |
| --- | --- | --- |
| `modelValue` | `DateRange`, a `[start, end]` pair of `YYYY-MM-DD` strings | |
| `shortcuts` | `DateRangeShortcut[]` | `[]` |
| `maxRangeDays` | `number` | |
| `placeholder` | `string` | `'Select date range...'` |
| `selectionLabel` | `(selectedRange: DateRange, activeShortcut?: DateRangeShortcut) => string` | |
| `ui` | The parts of the Date picker, plus `{ shortcuts?, shortcutLabel?, shortcutCheckIcon? }` | |

A `DateRangeShortcut` has a `label` and a `value`, the `DateRange` it selects.

### Slots

| Slot | Props | Description |
| --- | --- | --- |
| `selection` | `{ selectedRange, activeShortcut }` | Replaces the selected range shown in the date range picker. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `DateRange \| undefined` |
| `update:open` | `boolean` |
