---
title: Input
description: A compact text input without a label, for toolbars, filters, search and inline values like a page number.
---

## Usage

Use the `v-model` directive to control the value of the input. The input has no label of its own: name it with `aria-label`, or link a visible `<label>` to its `id`. In a form, use the [Text field](/components/forms/text-field) for a floating label, a hint and an error message.

::code-preview
:::div{class="w-full max-w-xs"}
::::k-input{aria-label="Full name" model-value="Avery Collins"}
::::
:::

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const fullName = ref('Avery Collins')
</script>

<template>
  <KInput v-model="fullName" aria-label="Full name" />
</template>
```
::

### Label

The input lines up with a label placed above it. Give it an `id` and point the label's `for` at it.

::code-preview
:input-label-example

#code
```vue
<label for="full-name" class="mb-1 block text-sm font-medium">Full name</label>
<KInput id="full-name" v-model="fullName" name="full-name" autocomplete="name" />
```
::

### Placeholder

Use the `placeholder` prop to show a hint while the input is empty.

::code-preview
:::div{class="w-full max-w-xs"}
::::k-input{placeholder="Enter text..." aria-label="Full name"}
::::
:::

#code
```vue
<KInput placeholder="Enter text..." aria-label="Full name" />
```
::

### Type

Use the `type` prop to change the type of the input. Defaults to `text`. A `number` input hides its arrows, and a `search` input hides the browser's own clear button, so use `clearable` for that.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-3"}
::::k-input{type="email" model-value="avery.collins@example.com" aria-label="Email address"}
::::

::::k-input{type="password" model-value="kuina-2026" aria-label="Password"}
::::

::::k-input{type="number" model-value="3" aria-label="Quantity"}
::::
:::

#code
```vue
<KInput type="email" aria-label="Email address" />
<KInput type="password" aria-label="Password" />
<KInput type="number" aria-label="Quantity" />
```
::

### Mask

Use the `mask` prop to format what is typed. It works like on the [Text field](/components/forms/text-field#mask): `#` stands for a digit, `@` for a letter and `*` for either, and `v-model:unmasked` gets only the typed characters.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-2"}
::::k-input{mask="#### #### #### ####" inputmode="numeric" placeholder="Card number" aria-label="Card number"}
::::

::::k-input{mask="##:##" inputmode="numeric" placeholder="09:30" aria-label="Time"}
::::
:::

#code
```vue
<KInput v-model="cardNumber" mask="#### #### #### ####" inputmode="numeric" aria-label="Card number" />
<KInput v-model:unmasked="timeDigits" mask="##:##" inputmode="numeric" aria-label="Time" />
```
::

### Variant

Use the `variant` prop to change the look of the input: `outline` (default) or `soft`.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-2"}
::::k-input{variant="outline" placeholder="Outline" aria-label="Outline"}
::::

::::k-input{variant="soft" placeholder="Soft" aria-label="Soft"}
::::
:::

#code
```vue
<KInput variant="outline" placeholder="Outline" aria-label="Outline" />
<KInput variant="soft" placeholder="Soft" aria-label="Soft" />
```
::

### Size

Use the `size` prop to change the size of the input, from `3xs` to `4xl`. Defaults to `md`. An input lines up with a [Button](/components/elements/button) or a [Select](/components/forms/select) of the same size.

::code-preview
:::div{class="flex w-full flex-col items-start gap-3"}
::::k-input{size="3xs" placeholder="3xs" aria-label="3xs" class="w-60"}
::::

::::k-input{size="xs" placeholder="xs" aria-label="xs" class="w-60"}
::::

::::k-input{size="md" placeholder="md" aria-label="md" class="w-60"}
::::

::::k-input{size="xl" placeholder="xl" aria-label="xl" class="w-60"}
::::

::::k-input{size="2xl" placeholder="2xl" aria-label="2xl" class="w-60"}
::::

::::k-input{size="4xl" placeholder="4xl" aria-label="4xl" class="w-60"}
::::
:::

#code
```vue
<KInput size="3xs" placeholder="3xs" aria-label="3xs" />
<KInput size="md" placeholder="md" aria-label="md" />
<KInput size="4xl" placeholder="4xl" aria-label="4xl" />
```
::

### Pill

Inputs are pills by default. Set `pill` to `false` to get rounded corners that follow the size.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-2"}
::::k-input{placeholder="Pill" aria-label="Pill"}
::::

::::k-input{placeholder="Rounded" aria-label="Rounded" :pill="false"}
::::
:::

#code
```vue
<KInput placeholder="Pill" aria-label="Pill" />
<KInput placeholder="Rounded" aria-label="Rounded" :pill="false" />
```
::

### Align

Use the `align` prop to align the text: `start` (default), `center` or `end`. It follows the reading direction, so `end` is on the left in a right-to-left page.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-3"}
::::k-input{model-value="Start" aria-label="Start"}
::::

::::k-input{model-value="Center" align="center" aria-label="Center"}
::::

::::k-input{model-value="1,250.00" align="end" inputmode="decimal" aria-label="Amount"}
::::
:::

#code
```vue
<KInput aria-label="Start" />
<KInput align="center" aria-label="Center" />
<KInput align="end" inputmode="decimal" aria-label="Amount" />
```
::

### Icon

Use the `leading-icon` and `trailing-icon` props to show an icon at the start or the end of the input. They take a [Lucide](https://lucide.dev/guide/packages/lucide-vue-next) icon component. A click on an icon puts the focus in the input.

::code-preview
:input-icons-example

#code
```vue
<script setup lang="ts">
import { AtSign, Banknote, Search } from 'lucide-vue-next'
</script>

<template>
  <KInput type="search" placeholder="Search transactions" aria-label="Search transactions" :leading-icon="Search" />
  <KInput inputmode="decimal" align="end" aria-label="Amount" :leading-icon="Banknote" />
  <KInput type="email" placeholder="jane.doe@example.com" aria-label="Email address" :trailing-icon="AtSign" />
</template>
```
::

### Clearable

Add `clearable` to show a button that empties the input once it has a value. It puts the focus back in the input and emits `clear`. Use `clear-label` to translate its label, `Clear` by default.

::code-preview
:input-clearable-example

#code
```vue
<KInput v-model="searchQuery" type="search" aria-label="Search transactions" :leading-icon="Search" clearable />
<KInput v-model="searchQuery" type="search" variant="soft" aria-label="Search transactions" :pill="false" clearable />
```
::

### Custom content

Use the `leading` and `trailing` slots to put your own content at the start or the end of the input, like a character count or a prefix. They replace the icons.

::code-preview
:input-slots-example

#code
```vue
<KInput v-model="username" placeholder="Username" aria-label="Username" maxlength="16" :pill="false">
  <template #trailing>
    <span class="text-xs text-muted tabular-nums">{{ username.length }}/16</span>
  </template>
</KInput>

<KInput v-model="website" type="url" aria-label="Website" :pill="false">
  <template #leading>
    <span class="text-muted">https://</span>
  </template>
</KInput>
```
::

### Optical alignment

Set `optically-align` to `start` or `end` to pull the input out by its inner padding, so that its text lines up with the content around it, like a label.

::code-preview
:input-optical-alignment-example

#code
```vue
<label for="field" class="mb-1 block text-sm">Field</label>
<KInput id="field" placeholder="Sample input" optically-align="start" />
```
::

### Invalid

Use the `invalid` prop to turn the input red and set `aria-invalid`. You decide when to remove it, for example when the value changes or when the form is sent.

::code-preview
:::div{class="grid w-full gap-4 sm:grid-cols-2"}
::::k-input{placeholder="Coupon code" aria-label="Coupon code" invalid}
::::

::::k-input{model-value="SPRING-25" variant="soft" aria-label="Coupon code" invalid}
::::
:::

#code
```vue
<KInput placeholder="Coupon code" aria-label="Coupon code" invalid />
<KInput v-model="couponCode" variant="soft" aria-label="Coupon code" invalid />
```
::

::

## Examples

### With a button

Give the input and the button the same `size` to put them side by side.

::code-preview
:::div{class="flex w-full max-w-md gap-2"}
::::k-input{type="email" placeholder="jane.doe@example.com" aria-label="Email address" size="lg"}
::::

::::k-button{label="Subscribe" size="lg"}
::::
:::

#code
```vue
<KInput v-model="email" type="email" placeholder="jane.doe@example.com" aria-label="Email address" size="lg" />
<KButton label="Subscribe" size="lg" />
```
::

### Page number

A small centered input, like the page field of a pagination. The `ui` prop narrows the radius.

::code-preview
:::div{class="flex items-center gap-2 text-sm"}
::::k-input{model-value="3" inputmode="numeric" align="center" size="xs" aria-label="Page" aria-describedby="page-count" :pill="false" class="w-12 tabular-nums" :ui='{"root": "rounded-sm"}'}
::::

:span[of 12]{id="page-count"}
:::

#code
```vue
<KInput
  v-model="page"
  inputmode="numeric"
  align="center"
  size="xs"
  aria-label="Page"
  aria-describedby="page-count"
  :pill="false"
  class="w-12 tabular-nums"
  :ui="{ root: 'rounded-sm' }"
/>
<span id="page-count">of 12</span>
```
::

### Select on open

Set `auto-select` to select the whole value when the input appears, or each time the prop turns to `true`, for example to copy a link.

```vue
<KInput model-value="https://kuina.dev/invite/4821" aria-label="Invite link" readonly auto-select />
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `modelValue` | `string` | |
| `id` | `string` | |
| `type` | `'text' \| 'email' \| 'password' \| 'search' \| 'tel' \| 'url' \| 'number'` | `'text'` |
| `placeholder` | `string` | |
| `mask` | `string \| string[] \| MaskSettings`, see [useMask](/composables/use-mask#mask-options) | |
| `unmasked` | `string`, with `v-model:unmasked` | |
| `variant` | `'outline' \| 'soft'` | `'outline'` |
| `size` | `'3xs' \| '2xs' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| '3xl' \| '4xl'` | `'md'` |
| `pill` | `boolean` | `true` |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` |
| `opticallyAlign` | `'start' \| 'end'` | |
| `leadingIcon` | `Component` | |
| `trailingIcon` | `Component` | |
| `clearable` | `boolean` | `false` |
| `clearLabel` | `string` | `'Clear'` |
| `autoSelect` | `boolean` | `false` |
| `allowAutofillExtensions` | `boolean` | `true` when `type` is `password` or the input has a `name` or an `autocomplete` |
| `invalid` | `boolean` | `false` |
| `readonly` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `ui` | `{ root?, base?, leading?, leadingIcon?, trailing?, trailingIcon?, clearButton?, clearIcon? }` | |
| `class` | `string` | |

Other attributes, like `aria-label`, `name`, `autocomplete`, `inputmode` or `maxlength`, and listeners like `@blur` go to the `<input>`. Without `allowAutofillExtensions`, password managers like 1Password and LastPass stay away from the input.

### Slots

| Slot | Description |
| --- | --- |
| `leading` | Content at the start of the input. Replaces the leading icon. |
| `trailing` | Content at the end of the input, before the clear button. Replaces the trailing icon. |

### Emits

| Event | Payload |
| --- | --- |
| `update:modelValue` | `string` |
| `update:unmasked` | `string`, with `mask` |
| `clear` | |
