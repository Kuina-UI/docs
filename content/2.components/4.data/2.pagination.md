---
title: Pagination
description: Move between the pages of a table or a list, and choose how many rows each page shows.
---

## Usage

Use `v-model:page` for the current page, `v-model:rows-per-page` for the rows on each page, and `total-row-count` for the number of rows to cut into pages.

::code-preview
:pagination-usage-example

#code
```vue
<script setup lang="ts">
const page = ref(3)
const rowsPerPage = ref(10)
</script>

<template>
  <KPagination v-model:page="page" v-model:rows-per-page="rowsPerPage" :total-row-count="128" />
</template>
```
::

**Previous** and **Next** turn off on the first and the last page. The page field takes a typed page on :kbd{value="Enter"} or when it loses the focus, kept between `1` and the last page; :kbd{value="↑"} and :kbd{value="↓"} move one page. Changing the rows per page keeps the first shown row on screen.

### With a table

The pagination stays outside the [Table](/components/data/table), so you place it where you like. Share the page and the rows per page between them, and give the pagination the number of matching rows from `v-model:matching-row-count`.

::code-preview
:table-pages-example

#code
```vue
<script setup lang="ts">
const page = ref(1)
const rowsPerPage = ref(5)
const matchingTransactionCount = ref(0)
</script>

<template>
  <KTable
    v-model:page="page"
    v-model:matching-row-count="matchingTransactionCount"
    :columns="transactionColumns"
    :rows="transactions"
    :rows-per-page="rowsPerPage"
  />
  <KPagination
    v-model:page="page"
    v-model:rows-per-page="rowsPerPage"
    :total-row-count="matchingTransactionCount"
    :rows-per-page-options="[5, 10, 25]"
  />
</template>
```
::

With [server data](/components/data/table#server-data), pass the total your server returns to `total-row-count`, or its number of pages to `page-count`.

### Rows per page

Use `rows-per-page-options` to change the choices, `[5, 10, 25, 50, 100]` by default. Pass an empty list to hide the choice.

```vue
<KPagination v-model:page="page" :total-row-count="128" :rows-per-page-options="[]" />
```

### Translation

Every text is a prop: `label` names the pagination for screen readers, then `rows-per-page-label`, `page-label`, `previous-label`, `next-label`, and `page-count-label`, a function that writes the total.

```vue
<KPagination
  v-model:page="page"
  v-model:rows-per-page="rowsPerPage"
  :total-row-count="128"
  label="Pagination"
  rows-per-page-label="Lignes par page"
  page-label="Page"
  previous-label="Précédent"
  next-label="Suivant"
  :page-count-label="(pageCount) => `sur ${pageCount}`"
/>
```

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `page` | `number`, with `v-model:page` | `1` |
| `rowsPerPage` | `number`, with `v-model:rows-per-page` | `10` |
| `totalRowCount` | `number` | |
| `pageCount` | `number` | from `totalRowCount` and `rowsPerPage` |
| `rowsPerPageOptions` | `number[]` | `[5, 10, 25, 50, 100]` |
| `disabled` | `boolean` | `false` |
| `label` | `string` | `'Pagination'` |
| `rowsPerPageLabel` | `string` | `'Rows per page'` |
| `pageLabel` | `string` | `'Page'` |
| `pageCountLabel` | `(pageCount: number) => string` | `` (pageCount) => `of ${pageCount}` `` |
| `previousLabel` | `string` | `'Previous'` |
| `nextLabel` | `string` | `'Next'` |
| `ui` | `{ root?, rowsPerPage?, rowsPerPageLabel?, controls?, pageField?, pageInput?, pageCount? }` | |
| `class` | `string` | |

### Emits

| Event | Payload |
| --- | --- |
| `update:page` | `number` |
| `update:rowsPerPage` | `number` |
