## Usage

Pass your records to the `rows` prop. Without columns, the table builds them from the fields of the first row, with readable labels and a type guessed from each value.

::code-preview
:::div{class="w-full"}
::::k-table{caption="Recent transactions" locale="en-US" :rows='[{"id":"txn-1048","merchant":"Corner Coffee","date":"2026-11-24","amount":-6.75},{"id":"txn-1047","merchant":"Acme Corp","date":"2026-11-21","amount":4850}]'}
::::
:::

#code
```vue
<KTable caption="Recent transactions" :rows="transactions" />
```
::

Each row needs a key that no other row has, `id` by default. Use the `row-key` prop to read it from another field, or from a function. In development, the table warns about rows without a key or sharing one.

Use the `caption` prop to name the table for screen readers. It stays hidden unless you set `show-caption`.

### Columns

Use the `columns` prop to choose and order the columns. `defineTableColumns` gives you autocompletion on the keys and paths of your rows.

::code-preview
:table-usage-example

#code
```vue
<script setup lang="ts">
const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'status', label: 'Status' },
  { key: 'amount', label: 'Amount', type: 'decimal', formatOptions: { style: 'currency', currency: 'USD' } },
])
</script>

<template>
  <KTable caption="Recent transactions" :columns="transactionColumns" :rows="transactions">
    <template #merchant-cell="{ row }">
      <span class="block font-medium">{{ row.merchant }}</span>
      <span class="block text-muted">{{ row.category }}</span>
    </template>

    <template #status-cell="{ row }">
      <KBadge :label="row.status" :color="statusColors[row.status]" dot />
    </template>
  </KTable>
</template>
```
::

A column shows the field named by its `key`. Use `accessor` to read something else: a path like `'customer.email'`, or a function like `(transaction) => transaction.amount - transaction.fee`. The `key` still names the column, its slots, its sort and its filter.

### Types and formats

The `type` of a column formats and aligns its values with `Intl`, in the language of the `locale` prop, or of the browser.

| Type | Shows | Aligned |
| --- | --- | --- |
| `text` (default) | The value as it is | Start |
| `number` | `4,850` | End, with numbers of the same width |
| `decimal` | `4,850.00` | End |
| `percentage` | `12.5%` for `0.125` | End |
| `date` | `Nov 24, 2026` for `'2026-11-24'`, which stays the same day in every time zone | Start |
| `boolean` | A check mark, or a dash | Center |

Use `formatOptions` to pass options to `Intl`, like a currency, and `format` to write the text yourself. Empty cells, `null`, `undefined` or `''`, stay empty. Use `align` to change the alignment.

```ts
{ key: 'amount', type: 'decimal', formatOptions: { style: 'currency', currency: 'EUR' } }
{ key: 'date', type: 'date', formatOptions: { month: 'long', day: 'numeric' } }
{ key: 'reference', format: (reference) => `#${reference}` }
```

### Custom cells

Use a slot named after the column key to draw its cells, like `#merchant-cell`, and its header, like `#amount-header`. A cell slot gets the `row`, the raw `value`, the `formattedValue`, the `column` and the `rowIndex`.

### Column types of your own

Use `defineTableColumnTypes` and the `column-types` prop to add types, with the same shape as the built-in ones: an `align`, a `format` and a `compare` for sorting.

::code-preview
:table-column-types-example

#code
```vue
<script setup lang="ts">
const statusOrder = { Failed: 0, Pending: 1, Completed: 2 }

const transactionColumnTypes = defineTableColumnTypes({
  status: {
    align: 'center',
    format: (status) => String(status).toUpperCase(),
    compare: (firstStatus, secondStatus) => statusOrder[firstStatus] - statusOrder[secondStatus],
  },
})

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'status', label: 'Status', type: 'status', sortable: true },
])
</script>

<template>
  <KTable :columns="transactionColumns" :column-types="transactionColumnTypes" :rows="transactions" />
</template>
```
::

## Sorting

Set `sortable` on a column to sort by it with a click on its header: first in one direction, then in the other, then not at all. Hold :kbd{value="Shift"} to add the column to the current sort instead; a small number then shows the order of each column.

::code-preview
:table-sorting-example

#code
```vue
<script setup lang="ts">
import type { TableSort } from '@kuina-ui/vue'

const transactionSort = ref<TableSort>([
  { key: 'category', direction: 'ascending' },
  { key: 'amount', direction: 'descending' },
])
</script>

<template>
  <KTable v-model:sort="transactionSort" :columns="transactionColumns" :rows="transactions" />
</template>
```
::

Use `v-model:sort` to read or set the sort, a list of `{ key, direction }`. A column sorts by the order of its type: text the way people read it, so `Invoice 2` comes before `Invoice 10`, numbers by value, dates by day. Empty cells always come last. Use `firstSortDirection` to start a column with `descending`, like dates, and `compare` to sort it your own way.

## Search and filters

The search field and the filters stay outside the table, wherever your page needs them. Pass the text to `search-query`, and the filters to `column-filters`, an object with a value for each column key.

::code-preview
:table-search-example

#code
```vue
<script setup lang="ts">
const searchQuery = ref('')
const categoryFilter = ref<string>()
const matchingTransactionCount = ref(0)
</script>

<template>
  <KInput v-model="searchQuery" type="search" aria-label="Search transactions" :leading-icon="Search" clearable />
  <KSelect v-model="categoryFilter" label="Category" :options="categoryOptions" :block="false" clearable />
  <span>{{ matchingTransactionCount }} transactions</span>

  <KTable
    v-model:matching-row-count="matchingTransactionCount"
    :columns="transactionColumns"
    :rows="transactions"
    :search-query="searchQuery"
    :column-filters="{ category: categoryFilter }"
  />
</template>
```
::

The search ignores case and accents, so `cafe` finds `Café`. It looks in the raw value and in the shown value of each column: `nov 21` finds the date `2026-11-21`. Set `searchable: false` on a column to leave it out, or pass your own `search-matcher`.

A filter keeps the rows whose value equals the filter value, or one of the values of a list. An empty value, `''`, `null`, `undefined` or `[]`, filters nothing. Give a column a `filter` function to compare your own way, like `(amount, wantsIncome) => wantsIncome === amount > 0`.

`v-model:matching-row-count` tells how many rows match, to show a count or to build your pagination.

## Selection

Set `selectable` to add a checkbox to each row and one to select all the rows shown. Use `v-model:selected-rows` to read or set the keys of the selected rows. The bar with your actions stays outside the table, so you choose its look and its texts.

::code-preview
:table-selection-example

#code
```vue
<script setup lang="ts">
const selectedTransactionIds = ref<string[]>([])
</script>

<template>
  <div v-if="selectedTransactionIds.length">
    {{ selectedTransactionIds.length }} selected
    <KButton label="Clear" variant="ghost" color="gray" size="xs" @click="selectedTransactionIds = []" />
    <KButton label="Delete" variant="ghost" color="danger" size="sm" :leading-icon="Trash2" />
  </div>

  <KTable
    v-model:selected-rows="selectedTransactionIds"
    :columns="transactionColumns"
    :rows="transactions"
    :is-row-selectable="(transaction) => transaction.status !== 'Failed'"
    selectable
  />
</template>
```
::

The box in the header selects the rows shown, and keeps the keys of rows on other pages. It shows a dash when only some of them are selected. Use `is-row-selectable` to keep some rows out of the selection.

## Pages

Use `rows-per-page` and `v-model:page` to show one page of rows at a time. The page goes back to the first one when the search, a filter or the sort changes, and moves back when the page no longer exists.

::code-preview
:table-pages-example

#code
```vue
<script setup lang="ts">
const page = ref(1)
const matchingTransactionCount = ref(0)
const pageCount = computed(() => Math.max(1, Math.ceil(matchingTransactionCount.value / 4)))
</script>

<template>
  <KTable
    v-model:page="page"
    v-model:matching-row-count="matchingTransactionCount"
    :columns="transactionColumns"
    :rows="transactions"
    :rows-per-page="4"
  />
  <KButton label="Previous" :disabled="page <= 1" @click="page--" />
  <span>Page {{ page }} of {{ pageCount }}</span>
  <KButton label="Next" :disabled="page >= pageCount" @click="page++" />
</template>
```
::

## Server data

Set `server-side` when your server searches, filters, sorts and cuts the pages. The table then shows the rows as they come, and only reports what the user asks through `v-model:sort` and `v-model:page`. Load the rows in your own code, and show `loading` meanwhile.

::code-preview
:table-server-side-example

#code
```vue
<script setup lang="ts">
const searchQuery = ref('')
const sort = ref<TableSort>([])
const transactions = shallowRef<Transaction[]>([])
const isLoading = ref(false)

watch([searchQuery, sort], async ([currentSearchQuery, currentSort]) => {
  isLoading.value = true
  transactions.value = await fetchTransactions({ search: currentSearchQuery, sort: currentSort })
  isLoading.value = false
}, { immediate: true })
</script>

<template>
  <KInput v-model.lazy="searchQuery" type="search" aria-label="Search transactions" />
  <KTable v-model:sort="sort" :columns="transactionColumns" :rows="transactions" :loading="isLoading" server-side />
</template>
```
::

## Appearance

### Fixed row height

Use `row-height` to give every row the same height, in pixels. Texts stay on one line. Give a column a `max-width` to cut its long texts with an ellipsis: the whole text shows in a tooltip, only when it is cut.

::code-preview
:table-row-height-example

#code
```vue
<script setup lang="ts">
const purchaseColumns = defineTableColumns<Purchase>([
  { key: 'merchant', label: 'Merchant', maxWidth: '10rem' },
  { key: 'category', label: 'Category', maxWidth: '6rem' },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])
</script>

<template>
  <KTable :columns="purchaseColumns" :rows="purchases" :row-height="40" />
</template>
```
::

<KTable variant="card" :columns="transactionColumns" :rows="transactions" />
```

### Dividers

```

### Size

Use the `size` prop to change the space around each row: `sm`, `md` (default) or `lg`.

::code-preview
:table-appearance-example{size="sm"}

#code
```vue
<KTable size="sm" :columns="transactionColumns" :rows="transactions" />
```

### Striped and hoverable

Set `striped` to shade every other row, and `hoverable` to shade the row under the pointer, useful with `@row-click`.

::code-preview
:table-appearance-example{striped hoverable}

#code
```vue
<KTable striped hoverable :columns="transactionColumns" :rows="transactions" @row-click="openTransaction" />
```
::

### Row colors and classes

Use `row-color` to tint a row: `success`, `warning`, `danger` or `info`. Use `row-class` to add your own classes to a row, and `cellClass` on a column for its cells, as a class or a function of the row.

```vue
<KTable
  :columns="transactionColumns"
  :rows="transactions"
  :row-color="(transaction) => (transaction.status === 'Failed' ? 'danger' : undefined)"
/>
```

```ts
{ key: 'amount', type: 'decimal', cellClass: (transaction) => (transaction.amount < 0 ? 'light:text-red-600 dark:text-red-400' : '') }
```

### Header and caption

Set `hide-header` to keep the header for screen readers only, and `show-caption` to show the caption under the table.

::code-preview
:table-appearance-example{hide-header show-caption}

#code
```vue
<KTable caption="Recent transactions" hide-header show-caption :columns="transactionColumns" :rows="transactions" />
```
::

## Loading and empty

Set `loading` while rows load. Before the first rows, the table shows skeleton rows, `loading-row-count` of them; with rows already shown, it dims them under a spinner. With no rows, it shows `empty-text`, or the `empty` slot.

::code-preview
:table-states-example

#code
```vue
<KTable
  empty-text="No transactions yet"
  :columns="transactionColumns"
  :rows="transactions"
  :loading="isLoading"
  :loading-row-count="3"
/>
```
::

## Events

`row-click` and `row-dblclick` give the row and the mouse event, and are not emitted from a button, a link or a field inside the row. `cell-click` gives `{ row, column, value }` and the mouse event.

## Reuse the logic

The search, filters, sort, pages and selection of the table come from two composables you can use on their own, for a list of cards for example: [useTableRows](/composables/use-table-rows) and [useRowSelection](/composables/use-row-selection).
