## Usage

Pass your records to the `rows` prop. Without columns, the table builds them from the fields of the first row, with readable labels and a type guessed from each value.

::code-preview
:::div{class="w-full"}
::::k-table{caption="Recent transactions" locale="en-US" :rows='[{"id":"txn-1048","merchant":"Corner Coffee","date":"2026-11-24","amount":-6.75},{"id":"txn-1047","merchant":"Acme Corp","date":"2026-11-21","amount":4850}]'}
::::
:::

#code
```vue
<script setup lang="ts">
interface Transaction {
  id: string
  merchant: string
  date: string
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', date: '2026-11-24', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', date: '2026-11-21', amount: 4850 },
]
</script>

<template>
  <KTable caption="Recent transactions" :rows="transactions" />
</template>
```
::

Each row needs a key that no other row has, `id` by default. Use the `row-key` prop to read it from another field, or from a function. In development, the table warns about rows without a key or sharing one.

Use the `caption` prop to name the table for screen readers. It stays hidden unless you set `show-caption`.

### Columns

Use the `columns` prop to choose and order the columns. `defineTableColumns` gives you autocompletion on the keys and paths of your rows.

::code-preview
:table-usage-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  status: 'Completed' | 'Pending' | 'Failed'
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', status: 'Completed', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', category: 'Salary', date: '2026-11-21', status: 'Completed', amount: 4850 },
  { id: 'txn-1046', merchant: 'Streamly', category: 'Subscriptions', date: '2026-11-19', status: 'Pending', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', status: 'Failed', amount: -428.4 },
]

const statusColors = { Completed: 'success', Pending: 'warning', Failed: 'danger' } as const

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'status', label: 'Status' },
  {
    key: 'amount',
    label: 'Amount',
    type: 'decimal',
    formatOptions: { style: 'currency', currency: 'USD', signDisplay: 'exceptZero' },
  },
])
</script>

<template>
  <KTable caption="Recent transactions" :columns="transactionColumns" :rows="transactions">
    <template #merchant-cell="{ row }">
      <span class="block font-medium">{{ row.merchant }}</span>
      <span class="block text-muted">{{ row.category }}</span>
    </template>

    <template #status-cell="{ row }">
      <KBadge :label="row.status" :color="statusColors[row.status]" dot />
    </template>
  </KTable>
</template>
```
::

A column shows the field named by its `key`. Use `accessor` to read something else: a path like `'customer.email'`, or a function. The `key` still names the column, its slots, its sort and its filter.

```ts
import { defineTableColumns } from '@kuina-ui/vue'

interface Payment {
  id: string
  amount: number
  fee: number
  customer: { name: string; email: string }
}

const paymentColumns = defineTableColumns<Payment>([
  { key: 'email', label: 'Email', accessor: 'customer.email' },
  { key: 'net', label: 'Net', type: 'decimal', accessor: (payment) => payment.amount - payment.fee },
])
```

### Types and formats

The `type` of a column formats and aligns its values with `Intl`, in the language of the `locale` prop, or of the browser.

| Type | Shows | Aligned |
| --- | --- | --- |
| `text` (default) | The value as it is | Start |
| `number` | `4,850` | End, with numbers of the same width |
| `decimal` | `4,850.00` | End |
| `percentage` | `12.5%` for `0.125` | End |
| `date` | `Nov 24, 2026` for `'2026-11-24'`, which stays the same day in every time zone | Start |
| `boolean` | A check mark, or a dash | Center |

Use `formatOptions` to pass options to `Intl`, like a currency, and `format` to write the text yourself. Empty cells, `null`, `undefined` or `''`, stay empty. Use `align` to change the alignment.

```ts
import { defineTableColumns } from '@kuina-ui/vue'

interface Invoice {
  id: string
  reference: string
  issuedOn: string
  total: number
  isPaid: boolean
}

const invoiceColumns = defineTableColumns<Invoice>([
  { key: 'reference', label: 'Reference', format: (reference) => `#${reference}` },
  { key: 'issuedOn', label: 'Issued on', type: 'date', formatOptions: { month: 'long', day: 'numeric' } },
  { key: 'total', label: 'Total', type: 'decimal', formatOptions: { style: 'currency', currency: 'EUR' } },
  { key: 'isPaid', label: 'Paid', type: 'boolean' },
])
```

### Custom cells

Use a slot named after the column key to draw its cells, like `#merchant-cell`, and its header, like `#amount-header`. A cell slot gets the `row`, the raw `value`, the `formattedValue`, the `column` and the `rowIndex`, all typed from your rows.

```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  status: 'Completed' | 'Pending' | 'Failed'
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', status: 'Completed', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', category: 'Salary', date: '2026-11-21', status: 'Completed', amount: 4850 },
  { id: 'txn-1046', merchant: 'Streamly', category: 'Subscriptions', date: '2026-11-19', status: 'Pending', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', status: 'Failed', amount: -428.4 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'category', label: 'Category' },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])
</script>

<template>
  <KTable :columns="transactionColumns" :rows="transactions">
    <template #amount-cell="{ value, formattedValue }">
      <span :class="Number(value) < 0 ? 'light:text-red-600 dark:text-red-400' : ''">{{ formattedValue }}</span>
    </template>

    <template #amount-header="{ column }">{{ column.label }} (USD)</template>
  </KTable>
</template>
```

### Column types of your own

Use `defineTableColumnTypes` and the `column-types` prop to add types, with the same shape as the built-in ones: an `align`, a `format` and a `compare` for sorting.

::code-preview
:table-column-types-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns, defineTableColumnTypes } from '@kuina-ui/vue'

type TransactionStatus = 'Completed' | 'Pending' | 'Failed'

interface Transaction {
  id: string
  merchant: string
  status: TransactionStatus
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', status: 'Completed', amount: -6.75 },
  { id: 'txn-1046', merchant: 'Streamly', status: 'Pending', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', status: 'Failed', amount: -428.4 },
]

const statusOrder: Record<TransactionStatus, number> = { Failed: 0, Pending: 1, Completed: 2 }

const transactionColumnTypes = defineTableColumnTypes({
  status: {
    align: 'center',
    format: (status) => String(status).toUpperCase(),
    compare: (firstStatus, secondStatus) =>
      statusOrder[firstStatus as TransactionStatus] - statusOrder[secondStatus as TransactionStatus],
  },
})

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'status', label: 'Status', type: 'status', sortable: true },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])
</script>

<template>
  <KTable :columns="transactionColumns" :column-types="transactionColumnTypes" :rows="transactions" />
</template>
```
::

## Sorting

Set `sortable` on a column to sort by it with a click on its header: first in one direction, then in the other, then not at all. Hold :kbd{value="Shift"} to add the column to the current sort instead; a small number then shows the order of each column.

::code-preview
:table-sorting-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns, type TableSort } from '@kuina-ui/vue'
import { ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', category: 'Salary', date: '2026-11-21', amount: 4850 },
  { id: 'txn-1043', merchant: 'Green Bowl', category: 'Food & drink', date: '2026-11-12', amount: -15.42 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', amount: -428.4 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant', sortable: true },
  { key: 'category', label: 'Category', sortable: true },
  { key: 'date', label: 'Date', type: 'date', sortable: true, firstSortDirection: 'descending' },
  { key: 'amount', label: 'Amount', type: 'decimal', sortable: true },
])

const transactionSort = ref<TableSort>([
  { key: 'category', direction: 'ascending' },
  { key: 'amount', direction: 'descending' },
])
</script>

<template>
  <KTable v-model:sort="transactionSort" :columns="transactionColumns" :rows="transactions" />
</template>
```
::

Use `v-model:sort` to read or set the sort, a list of `{ key, direction }`. A column sorts by the order of its type: text the way people read it, so `Invoice 2` comes before `Invoice 10`, numbers by value, dates by day. Empty cells always come last. Use `firstSortDirection` to start a column with `descending`, like dates, and `compare` to sort it your own way.

## Search and filters

The search field and the filters stay outside the table, wherever your page needs them. Pass the text to `search-query`, and the filters to `column-filters`, an object with a value for each column key.

::code-preview
:table-search-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'
import { Search } from 'lucide-vue-next'
import { ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', category: 'Salary', date: '2026-11-21', amount: 4850 },
  { id: 'txn-1043', merchant: 'Green Bowl', category: 'Food & drink', date: '2026-11-12', amount: -15.42 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', amount: -428.4 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'category', label: 'Category', searchable: false },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])

const categoryOptions = ['Food & drink', 'Salary', 'Travel']

const searchQuery = ref('')
const categoryFilter = ref<string>()
const matchingTransactionCount = ref(0)
</script>

<template>
  <KInput
    v-model="searchQuery"
    type="search"
    placeholder="Search transactions"
    aria-label="Search transactions"
    :leading-icon="Search"
    clearable
  />
  <KSelect v-model="categoryFilter" label="Category" :options="categoryOptions" :block="false" clearable />
  <span>{{ matchingTransactionCount }} transactions</span>

  <KTable
    v-model:matching-row-count="matchingTransactionCount"
    :columns="transactionColumns"
    :rows="transactions"
    :search-query="searchQuery"
    :column-filters="{ category: categoryFilter }"
  />
</template>
```
::

The search ignores case and accents, so `cafe` finds `Café`. It looks in the raw value and in the shown value of each column: `nov 21` finds the date `2026-11-21`. Set `searchable: false` on a column to leave it out, or pass your own `search-matcher`.

A filter keeps the rows whose value equals the filter value, or one of the values of a list. An empty value, `''`, `null`, `undefined` or `[]`, filters nothing. Give a column a `filter` function to compare your own way, like income only:

```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'
import { ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  status: 'Completed' | 'Pending' | 'Failed'
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', status: 'Completed', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', category: 'Salary', date: '2026-11-21', status: 'Completed', amount: 4850 },
  { id: 'txn-1046', merchant: 'Streamly', category: 'Subscriptions', date: '2026-11-19', status: 'Pending', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', status: 'Failed', amount: -428.4 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  {
    key: 'amount',
    label: 'Amount',
    type: 'decimal',
    filter: (amount, wantsIncome) => wantsIncome === Number(amount) > 0,
  },
])

const showsIncomeOnly = ref(false)
</script>

<template>
  <KSwitch v-model="showsIncomeOnly" label="Income only" />
  <KTable
    :columns="transactionColumns"
    :rows="transactions"
    :column-filters="{ amount: showsIncomeOnly || undefined }"
  />
</template>
```

`v-model:matching-row-count` tells how many rows match, to show a count or to build your pagination.

## Selection

Set `selectable` to add a checkbox to each row and one to select all the rows shown. Use `v-model:selected-rows` to read or set the keys of the selected rows. The bar with your actions stays outside the table, so you choose its look and its texts.

::code-preview
:table-selection-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'
import { Download, Trash2 } from 'lucide-vue-next'
import { ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  date: string
  status: 'Completed' | 'Pending' | 'Failed'
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', date: '2026-11-24', status: 'Completed', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', date: '2026-11-21', status: 'Completed', amount: 4850 },
  { id: 'txn-1046', merchant: 'Streamly', date: '2026-11-19', status: 'Pending', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', date: '2026-11-16', status: 'Failed', amount: -428.4 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'status', label: 'Status' },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])

const selectedTransactionIds = ref<string[]>(['txn-1048', 'txn-1046'])

function deleteTransactions(transactionIds: string[]) {
  console.log('Delete', transactionIds)
}
</script>

<template>
  <div v-if="selectedTransactionIds.length" class="flex items-center gap-2 ps-3 pe-3 text-sm">
    <span class="font-medium">{{ selectedTransactionIds.length }} selected</span>
    <KButton label="Clear" variant="ghost" color="gray" size="xs" @click="selectedTransactionIds = []" />
    <span class="ms-auto -me-3.25 flex items-center gap-1">
      <KButton label="Export" variant="ghost" color="gray" size="sm" :leading-icon="Download" />
      <KButton
        label="Delete"
        variant="ghost"
        color="danger"
        size="sm"
        :leading-icon="Trash2"
        @click="deleteTransactions(selectedTransactionIds)"
      />
    </span>
  </div>

  <KTable
    v-model:selected-rows="selectedTransactionIds"
    :columns="transactionColumns"
    :rows="transactions"
    :is-row-selectable="(transaction) => transaction.status !== 'Failed'"
    selectable
  />
</template>
```
::

The box in the header selects the rows shown, and keeps the keys of rows on other pages. It shows a dash when only some of them are selected. Use `is-row-selectable` to keep some rows out of the selection.

## Row details

Use the `expanded` slot to show the details of a row under it. A button at the start of each row opens and closes them, and `v-model:expanded-rows` holds the keys of the open rows.

::code-preview

## Groups

Use `group-by` with a column key, or any path of your rows, to gather the rows that share a value under a group header. The header shows the shown value of that column, the number of rows, and a total for each column that has an `aggregate`.

::code-preview
:table-groups-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'
import { ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  category: string
  date: string
  amount: number
}

const transactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', category: 'Food & drink', date: '2026-11-24', amount: -6.75 },
  { id: 'txn-1046', merchant: 'Streamly', category: 'Subscriptions', date: '2026-11-19', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', category: 'Travel', date: '2026-11-16', amount: -428.4 },
  { id: 'txn-1043', merchant: 'Green Bowl', category: 'Food & drink', date: '2026-11-12', amount: -15.42 },
  { id: 'txn-1042', merchant: 'Cineflix', category: 'Subscriptions', date: '2026-11-10', amount: -15.49 },
  { id: 'txn-1040', merchant: 'City Rides', category: 'Travel', date: '2026-11-06', amount: -24.6 },
]

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'date', label: 'Date', type: 'date' },
  {
    key: 'amount',
    label: 'Amount',
    type: 'decimal',
    formatOptions: { style: 'currency', currency: 'USD' },
    aggregate: 'sum',
  },
])

const collapsedCategories = ref<string[]>(['Travel'])
</script>

<template>
  <KTable
    v-model:collapsed-groups="collapsedCategories"
    group-by="category"
    :columns="transactionColumns"
    :rows="transactions"
  />
</template>
```
::

The groups keep the order in which their first row appears, so the sort orders them too. A button collapses each group, and `v-model:collapsed-groups` holds the values of the collapsed ones. Use `group-label` to write the header yourself, like `` (category, rows) => `${category} (${rows.length})` ``.

An `aggregate` is `sum`, `average`, `count`, `min`, `max`, or a function that gets the rows of the group. The total is formatted with the type and the `formatOptions` of its column.

## Tree

Give rows a `children` list to show them as a tree: a button on the first column opens a row and shows its children under it, one level deeper. `v-model:expanded-rows` holds the keys of the open rows. Use `children-key` to read the children from another field.

## Reordering

Set `reorderable` to add a handle at the start of each row. Drag the handle to move the row, or focus it and press :kbd{value="↑"} or :kbd{value="↓"}, :kbd{value="Home"} or :kbd{value="End"}. Use `v-model:rows` to keep the new order.

::code-preview
:table-reorder-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns, type TableReorderPayload } from '@kuina-ui/vue'
import { ref } from 'vue'

  id: string
  category: string
  budget: number
  spent: number
}

const budgetLines = ref<BudgetLine[]>([

  { key: 'category', label: 'Category' },
```

The dragged row moves to its new place while you drag it, and lands on drop. :kbd{value="Escape"} cancels the drag. `reorder` sends `{ row, fromIndex, toIndex, rows }`, with the positions in `rows`, to save the order on your server.

A row moves within the page you see. The handles turn off while the shown order is not the order of `rows`: when the table is sorted, searched, filtered, grouped, has pinned rows or is a tree.

Give `row-menu` a function that returns the menu entries of a row. A right click on the row opens the [Menu](/components/overlays/menu) at the pointer, and the row stays highlighted while it is open. :kbd{value="Shift"} :kbd{value="F10"} opens it from the keyboard.

## Server data

Set `server-side` when your server searches, sorts and cuts the pages. The table then shows the rows as they come, and only reports what the user asks: the sort through `v-model:sort` and the page through `v-model:page`. Your code sends them to the server with the search and the rows per page, then gives the table the rows and the pagination the total.

::code-preview
:table-server-side-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns, type TableSort } from '@kuina-ui/vue'
import { Search } from 'lucide-vue-next'
import { ref, shallowRef, watch } from 'vue'

interface Transaction {
  id: string
  merchant: string
  date: string
  amount: number
}

interface TransactionPage {
  rows: Transaction[]
  total: number
}

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant', sortable: true },
  { key: 'date', label: 'Date', type: 'date', sortable: true },
  { key: 'amount', label: 'Amount', type: 'decimal', sortable: true },
])

const searchQuery = ref('')
const sort = ref<TableSort>([])
const page = ref(1)
const rowsPerPage = ref(5)
const transactions = shallowRef<Transaction[]>([])
const totalTransactionCount = ref(0)
const isLoading = ref(false)

async function fetchTransactionPage() {
  const requestParameters = new URLSearchParams({
    search: searchQuery.value,
    sort: JSON.stringify(sort.value),
    page: String(page.value),
    rowsPerPage: String(rowsPerPage.value),
  })
  const response = await fetch(`/api/transactions?${requestParameters}`)

  return (await response.json()) as TransactionPage
}

let latestRequestNumber = 0

watch(
  [searchQuery, sort, page, rowsPerPage],
  async () => {
    const requestNumber = ++latestRequestNumber
    isLoading.value = true
    const transactionPage = await fetchTransactionPage()

    if (requestNumber !== latestRequestNumber) return

    transactions.value = transactionPage.rows
    totalTransactionCount.value = transactionPage.total
    isLoading.value = false
  },
  { immediate: true },
)
</script>

<template>
  <KInput
    v-model.lazy="searchQuery"
    type="search"
    placeholder="Search, then press Enter"
    aria-label="Search transactions"
    :leading-icon="Search"
  />
  <KTable
    v-model:sort="sort"
    v-model:page="page"
    :columns="transactionColumns"
    :rows="transactions"
    :loading="isLoading"
    server-side
  />
  <KPagination
    v-model:page="page"
    v-model:rows-per-page="rowsPerPage"
    :total-row-count="totalTransactionCount"
    :rows-per-page-options="[5, 10, 25]"
  />
</template>
```
::

What happens, step by step:

1. The user types a search, clicks a header or changes the page.
2. The table updates `sort` or `page`, and goes back to the first page when the search or the sort changes.
3. The `watch` sends the search, the sort, the page and the rows per page to your server, and shows `loading` meanwhile.
4. The server returns the rows of that page and the total number of matching rows: the rows go to the table, the total to the pagination.

`latestRequestNumber` keeps only the answer to the latest request: when the user types fast, an older answer that arrives late does not replace the newer one. `v-model.lazy` sends the search on :kbd{value="Enter"} or when the field loses the focus; use a debounce to search while typing.

Your server reads the same four values and answers `{ rows, total }`. With Nuxt, the route could look like this:

```ts [server/api/transactions.get.ts]
import type { TableSort } from '@kuina-ui/vue'

interface Transaction {
  id: string
  merchant: string
  date: string
  amount: number
}

const storedTransactions: Transaction[] = [
  { id: 'txn-1048', merchant: 'Corner Coffee', date: '2026-11-24', amount: -6.75 },
  { id: 'txn-1047', merchant: 'Acme Corp', date: '2026-11-21', amount: 4850 },
  { id: 'txn-1046', merchant: 'Streamly', date: '2026-11-19', amount: -11.99 },
  { id: 'txn-1045', merchant: 'Skyway Airlines', date: '2026-11-16', amount: -428.4 },
]

export default defineEventHandler((event) => {
  const query = getQuery(event)
  const search = String(query.search ?? '').toLowerCase()
  const sort = JSON.parse(String(query.sort ?? '[]')) as TableSort
  const page = Number(query.page ?? 1)
  const rowsPerPage = Number(query.rowsPerPage ?? 25)

  const matchingTransactions = storedTransactions.filter((transaction) =>
    transaction.merchant.toLowerCase().includes(search),
  )

  const [sortEntry] = sort

  if (sortEntry) {
    const sortKey = sortEntry.key as keyof Transaction
    const sortSign = sortEntry.direction === 'ascending' ? 1 : -1

    matchingTransactions.sort((firstTransaction, secondTransaction) =>
      firstTransaction[sortKey] > secondTransaction[sortKey] ? sortSign : -sortSign,
    )
  }

  const firstRowIndex = (page - 1) * rowsPerPage

  return {
    rows: matchingTransactions.slice(firstRowIndex, firstRowIndex + rowsPerPage),
    total: matchingTransactions.length,
  }
})
```

In a real project, the search, the sort and the pages usually go to your database query instead, like `ORDER BY` and `LIMIT … OFFSET …` in SQL.

## Infinite loading

Instead of pages, load the next rows when the end of the table comes near. The table sends `load-more` once for each number of rows, about 200 pixels before the end: in its own scroll area when it has a `max-height`, or in the page. Show `loading-more` while the rows load.

::code-preview
:table-infinite-loading-example

#code
```vue
<script setup lang="ts">
import { defineTableColumns } from '@kuina-ui/vue'
import { onMounted, ref } from 'vue'

interface Transaction {
  id: string
  merchant: string
  date: string
  amount: number
}

interface TransactionPage {
  rows: Transaction[]
  total: number
}

const transactionColumns = defineTableColumns<Transaction>([
  { key: 'merchant', label: 'Merchant' },
  { key: 'date', label: 'Date', type: 'date' },
  { key: 'amount', label: 'Amount', type: 'decimal' },
])

const transactions = ref<Transaction[]>([])
const totalTransactionCount = ref<number>()
const isLoadingMore = ref(false)

async function loadMoreTransactions() {
  const hasLoadedEverything = totalTransactionCount.value !== undefined && transactions.value.length >= totalTransactionCount.value

  if (isLoadingMore.value || hasLoadedEverything) return

  isLoadingMore.value = true

  const response = await fetch(`/api/transactions?offset=${transactions.value.length}&limit=20`)
  const transactionPage: TransactionPage = await response.json()

  transactions.value = [...transactions.value, ...transactionPage.rows]
  totalTransactionCount.value = transactionPage.total
  isLoadingMore.value = false
}

onMounted(loadMoreTransactions)
</script>

<template>
  <KTable
    max-height="18rem"
    :columns="transactionColumns"
    :rows="transactions"
    :loading="isLoadingMore && transactions.length === 0"
    :loading-more="isLoadingMore && transactions.length > 0"
    @load-more="loadMoreTransactions"
  />
</template>
```
::

The table does not ask again while `loading` or `loading-more` is on, nor while the number of rows stays the same, so a server with nothing more to send stops the loading by itself.

In a project, put this in a component of your own, like `TransactionsTable.vue`, and reuse it: the wiring and the way you load data from your server are written once. The table, its columns and its slots keep the type of your rows, so `row.status` stays typed in that component too.

## Reuse the logic

The search, filters, sort, pages and selection of the table come from two composables you can use on their own, for a list of cards for example: [useTableRows](/composables/use-table-rows) and [useRowSelection](/composables/use-row-selection).
