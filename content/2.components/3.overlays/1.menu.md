---
title: Menu
description: A button that opens a list of actions, links and options, usable with the mouse and the keyboard.
---

## Usage

### Label and items

Use the `label` prop to set the text of the button, which also names the menu for screen readers, and the `items` prop to fill the menu.

::code-preview
:k-menu{label="Options" :items='[{"label":"Edit"},{"label":"Duplicate"},{"separator":true},{"label":"Delete","color":"danger"}]'}

#code
```vue
<KMenu
  label="Options"
  :items="[{ label: 'Edit' }, { label: 'Duplicate' }, { separator: true }, { label: 'Delete', color: 'danger' }]"
/>
```
::

### Trigger

Use the `trigger` prop to style the button with the props of [Button](/components/elements/button): `variant`, `color`, `size`, `leadingIcon`, `trailingIcon`, `pill`, `square` and `disabled`. The button looks selected while the menu is open.

::code-preview
:menu-trigger-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry } from '@kuina-ui/vue'
import { ChevronDown, Download, Ellipsis, Eye, Flag, Pencil, Wrench } from 'lucide-vue-next'

const transactionActions: MenuEntry[] = [
  { label: 'Edit', icon: Pencil },
  { label: 'Download receipt', icon: Download },
]

const rowActions: MenuEntry[] = [
  { label: 'View details', icon: Eye },
  { label: 'Download receipt', icon: Download },
  { separator: true },
  { label: 'Report a problem', icon: Flag },
]
</script>

<template>
  <KMenu label="Options" :items="transactionActions" :trigger="{ variant: 'outline', trailingIcon: ChevronDown }" />
  <KMenu label="Tools" :items="transactionActions" :trigger="{ variant: 'ghost', leadingIcon: Wrench }" />
  <KMenu
    label="More actions"
    :items="rowActions"
    :trigger="{ variant: 'ghost', color: 'gray', leadingIcon: Ellipsis, square: true }"
    align="end"
    width="sm"
  />
</template>
```
::

### Items

An item has a `label` and can add an `icon`, a `description` and a `shortcut`. Give it an `href` to make it a link: links to another website open in a new tab. Set `color` to `danger` for destructive actions, and `disabled` to `true` to keep an item visible but unusable.

Between items, `{ separator: true }` draws a line, and `{ label, description, readOnly: true }` adds a heading that cannot be selected.

::code-preview
:menu-items-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry } from '@kuina-ui/vue'
import { ChevronDown, CircleUser, Copy, FileText, Flag, LogOut, Pencil, Share2, Trash2 } from 'lucide-vue-next'

const accountItems: MenuEntry[] = [
  { label: 'Avery Collins', description: 'avery.collins@example.com', readOnly: true },
  { separator: true },
  { label: 'Your profile', icon: CircleUser, href: '#' },
  { label: 'Terms & policies', icon: FileText, href: 'https://example.com/terms' },
  { label: 'Feature flags', icon: Flag, disabled: true },
  { separator: true },
  { label: 'Log out', icon: LogOut, color: 'danger' },
]

const transactionItems: MenuEntry[] = [
  { label: 'Edit', icon: Pencil, shortcut: '⌘E' },
  { label: 'Duplicate', icon: Copy, shortcut: '⌘D' },
  { label: 'Share', icon: Share2, description: 'Send a copy by email' },
  { separator: true },
  { label: 'Delete', icon: Trash2, shortcut: '⌘⌫', color: 'danger' },
]
</script>

<template>
  <KMenu label="Avery Collins" :items="accountItems" :trigger="{ variant: 'ghost', color: 'gray', trailingIcon: ChevronDown }" />
  <KMenu label="Options" :items="transactionItems" :trigger="{ variant: 'outline', trailingIcon: ChevronDown }" />
</template>
```
::

### Select an item

Give an item an `onSelect` function to run when it is chosen, with a click, :kbd{value="Enter"} or :kbd{value="Space"}. The menu then closes and gives the focus back to its button.

```vue
<script setup lang="ts">
import type { MenuEntry } from '@kuina-ui/vue'

const transactionItems: MenuEntry[] = [
  { label: 'Edit', onSelect: () => openTransactionEditor() },
  { label: 'Delete', color: 'danger', onSelect: () => deleteTransaction() },
]
</script>
```

### Checkbox items

Set `type` to `checkbox` and pass the state in `checked`. The menu stays open after a checkbox item is toggled, so several options can be changed in a row.

Use the `indicator-position` prop to put the check `start` or `end` (default), and the `indicator-variant` prop to show it `solid` (default) or `ghost`.

::code-preview
:menu-checkbox-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry } from '@kuina-ui/vue'
import { ChevronDown } from 'lucide-vue-next'
import { computed, reactive } from 'vue'

const chartOptions = reactive({ gridLines: true, labels: false, shadows: true })

function toggleChartOption(chartOptionName: keyof typeof chartOptions) {
  chartOptions[chartOptionName] = !chartOptions[chartOptionName]
}

const chartOptionItems = computed<MenuEntry[]>(() => [
  { label: 'Show grid lines', type: 'checkbox', checked: chartOptions.gridLines, onSelect: () => toggleChartOption('gridLines') },
  { label: 'Display labels', type: 'checkbox', checked: chartOptions.labels, onSelect: () => toggleChartOption('labels') },
  { label: 'Enable shadows', type: 'checkbox', checked: chartOptions.shadows, onSelect: () => toggleChartOption('shadows') },
  { label: 'Compare to last year', type: 'checkbox', disabled: true },
])
</script>

<template>
  <KMenu label="Chart options" :items="chartOptionItems" :trigger="{ variant: 'soft', trailingIcon: ChevronDown }" />
  <KMenu
    label="Chart options"
    :items="chartOptionItems"
    :trigger="{ variant: 'soft', trailingIcon: ChevronDown }"
    indicator-position="start"
    indicator-variant="ghost"
  />
</template>
```
::

### Radio items

Set `type` to `radio` for a choice between several options. Unlike a checkbox item, choosing one closes the menu.

::code-preview
:menu-radio-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry, MenuItem } from '@kuina-ui/vue'
import { ChevronDown } from 'lucide-vue-next'
import { computed, ref } from 'vue'

const reportPeriods = ['Any time', 'Today', 'Last 7 days', 'Last 30 days', 'Last 3 months']

const selectedPeriod = ref('Any time')

const periodItems = computed<MenuEntry[]>(() =>
  reportPeriods.map((reportPeriod): MenuItem => ({
    label: reportPeriod,
    type: 'radio',
    checked: selectedPeriod.value === reportPeriod,
    disabled: reportPeriod === 'Today',
    onSelect: () => {
      selectedPeriod.value = reportPeriod
    },
  })),
)
</script>

<template>
  <KMenu :label="selectedPeriod" :items="periodItems" :trigger="{ variant: 'soft', trailingIcon: ChevronDown }" width="auto" />
</template>
```
::

### Groups

Use `{ label, items }` to group items under a heading, which screen readers announce with the group.

::code-preview
:menu-groups-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry, MenuItem } from '@kuina-ui/vue'
import { SlidersHorizontal } from 'lucide-vue-next'
import { computed, reactive, ref } from 'vue'

const sortOrders = ['Newest first', 'Oldest first', 'Largest amount']

const selectedSortOrder = ref('Newest first')

const visibleTransactions = reactive({ pending: true, transfers: false, hidden: false })

function toggleVisibleTransactions(transactionKind: keyof typeof visibleTransactions) {
  visibleTransactions[transactionKind] = !visibleTransactions[transactionKind]
}

const transactionViewItems = computed<MenuEntry[]>(() => [
  {
    label: 'Sort by',
    items: sortOrders.map((sortOrder): MenuItem => ({
      label: sortOrder,
      type: 'radio',
      checked: selectedSortOrder.value === sortOrder,
      onSelect: () => {
        selectedSortOrder.value = sortOrder
      },
    })),
  },
  { separator: true },
  {
    label: 'Show',
    items: [
      { label: 'Pending', type: 'checkbox', checked: visibleTransactions.pending, onSelect: () => toggleVisibleTransactions('pending') },
      { label: 'Transfers', type: 'checkbox', checked: visibleTransactions.transfers, onSelect: () => toggleVisibleTransactions('transfers') },
      { label: 'Hidden transactions', type: 'checkbox', checked: visibleTransactions.hidden, onSelect: () => toggleVisibleTransactions('hidden') },
    ],
  },
])
</script>

<template>
  <KMenu label="View" :items="transactionViewItems" :trigger="{ variant: 'outline', leadingIcon: SlidersHorizontal }" indicator-position="start" />
</template>
```
::

### Side

Use the `side` prop to open the menu `bottom` (default) or `top` of its button.

::code-preview
:::div{class="flex flex-wrap items-center gap-2"}
:k-menu{label="Below" :trigger='{"variant":"outline"}' :items='[{"label":"Personal"},{"label":"Northwind Family"}]'} :k-menu{label="Above" side="top" :trigger='{"variant":"outline"}' :items='[{"label":"Personal"},{"label":"Northwind Family"}]'}
:::

#code
```vue
<KMenu label="Below" :trigger="{ variant: 'outline' }" :items="workspaces" />
<KMenu label="Above" side="top" :trigger="{ variant: 'outline' }" :items="workspaces" />
```
::

### Align

Use the `align` prop to line the menu up with the `start` (default), the `center` or the `end` of its button.

::code-preview
:::div{class="flex flex-wrap items-center gap-2"}
:k-menu{label="Start" width="sm" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"},{"label":"Excel"}]'} :k-menu{label="Center" align="center" width="sm" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"},{"label":"Excel"}]'} :k-menu{label="End" align="end" width="sm" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"},{"label":"Excel"}]'}
:::

#code
```vue
<KMenu label="Start" width="sm" :trigger="{ variant: 'outline' }" :items="exportFormats" />
<KMenu label="Center" align="center" width="sm" :trigger="{ variant: 'outline' }" :items="exportFormats" />
<KMenu label="End" align="end" width="sm" :trigger="{ variant: 'outline' }" :items="exportFormats" />
```
::

### Width

Use the `width` prop to set the width of the menu: `sm`, `md` (default), `lg` or `xl`. `auto` fits the items up to `max-w-80`, and `trigger` matches the width of the button.

::code-preview
:::div{class="flex flex-wrap items-center gap-2"}
:k-menu{label="Auto" width="auto" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"}]'} :k-menu{label="Large" width="lg" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"}]'} :k-menu{label="Same width as this button" width="trigger" :trigger='{"variant":"outline"}' :items='[{"label":"CSV"},{"label":"PDF"}]'}
:::

#code
```vue
<KMenu label="Auto" width="auto" :trigger="{ variant: 'outline' }" :items="exportFormats" />
<KMenu label="Large" width="lg" :trigger="{ variant: 'outline' }" :items="exportFormats" />
<KMenu label="Same width as this button" width="trigger" :trigger="{ variant: 'outline' }" :items="exportFormats" />
```
::

### Open state

Use `v-model:open` to know whether the menu is open, or to open and close it from your code.

::code-preview
:menu-open-state-example

#code
```vue
<script setup lang="ts">
import type { MenuEntry } from '@kuina-ui/vue'
import { ChevronDown } from 'lucide-vue-next'
import { ref } from 'vue'

const isMenuOpen = ref(false)

const exportFormats: MenuEntry[] = [{ label: 'CSV' }, { label: 'PDF' }, { label: 'Excel' }]
</script>

<template>
  <KMenu
    v-model:open="isMenuOpen"
    label="Export"
    :items="exportFormats"
    :trigger="{ variant: 'outline', trailingIcon: ChevronDown }"
    width="sm"
  />
  <p>The menu is {{ isMenuOpen ? 'open' : 'closed' }}.</p>
</template>
```
::

## Keyboard

| Key | Action |
| --- | --- |
| :kbd{value="Enter"}, :kbd{value="Space"} | On the button, opens the menu on its first item. On an item, selects it. |
| :kbd{value="↓"}, :kbd{value="↑"} | On the button, opens the menu on its first or last item. In the menu, moves to the next or previous item. |
| :kbd{value="Home"}, :kbd{value="End"} | Moves to the first or last item. |
| :kbd{value="Esc"} | Closes the menu and focuses the button. |
| :kbd{value="Tab"} | Closes the menu and moves on from the button. |

## Customization

Use the `ui` prop to change the classes of each part of the menu, and `class` for the root element. Your classes always win: `rounded-2xl` replaces the default `rounded-xl` of the panel instead of being added to it.

::code-preview
:k-menu{label="Rounder" :trigger='{"variant":"outline"}' :items='[{"label":"Edit"},{"label":"Duplicate"}]' :ui='{"panel":"rounded-2xl","item":"rounded-lg"}'}

#code
```vue
<KMenu
  label="Rounder"
  :trigger="{ variant: 'outline' }"
  :items="[{ label: 'Edit' }, { label: 'Duplicate' }]"
  :ui="{ panel: 'rounded-2xl', item: 'rounded-lg' }"
/>
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | |
| `items` | `MenuEntry[]` | |
| `open` | `boolean` | `false` |
| `trigger` | `{ variant?, color?, size?, leadingIcon?, trailingIcon?, pill?, square?, disabled? }` | |
| `side` | `'bottom' \| 'top'` | `'bottom'` |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` |
| `width` | `'trigger' \| 'auto' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` |
| `indicatorPosition` | `'start' \| 'end'` | `'end'` |
| `indicatorVariant` | `'solid' \| 'ghost'` | `'solid'` |
| `ui` | `{ root?, panel?, separator?, groupLabel?, header?, headerLabel?, headerDescription?, item?, itemContent?, itemIcon?, itemText?, itemLabel?, itemDescription?, itemShortcut?, indicatorWrapper?, indicator?, indicatorCheckIcon?, radioDot?, newTabHint? }` | |
| `class` | `string` | |

### Items

`MenuEntry` is one of these four shapes.

| Entry | Fields |
| --- | --- |
| Item | `label`, `description?`, `icon?`, `shortcut?`, `href?`, `color?: 'danger'`, `type?: 'checkbox' \| 'radio'`, `checked?`, `disabled?`, `onSelect?(event)` |
| Separator | `separator: true` |
| Group | `label`, `items: MenuItem[]` |
| Heading | `label`, `description?`, `readOnly: true` |

### Emits

| Event | Payload |
| --- | --- |
| `update:open` | `boolean` |
