---
title: Circular progress
description: A ring that fills up to show how far a task has gone, from 0 to 100.
---

## Usage

### Progress

Use the `progress` prop to set how much of the ring is filled, from `0` to `100`. Values outside this range are clamped.

::code-preview
:::div{class="flex flex-wrap items-center gap-4"}
:k-circular-progress{:progress="25"} :k-circular-progress{:progress="50"} :k-circular-progress{:progress="75"} :k-circular-progress{:progress="100"}
:::

#code
```vue
<KCircularProgress :progress="25" />
<KCircularProgress :progress="50" />
<KCircularProgress :progress="75" />
<KCircularProgress :progress="100" />
```
::

### Label

Use the `label` prop to set the name announced by screen readers. The default is `Progress`.

::code-preview
:k-circular-progress{:progress="60" label="Upload progress"}

#code
```vue
<KCircularProgress :progress="60" label="Upload progress" />
```
::

### Size

Use a `size-*` class to change the size of the ring.

::code-preview
:::div{class="flex flex-wrap items-center gap-4"}
:k-circular-progress{:progress="60"} :k-circular-progress{:progress="60" class="size-10"} :k-circular-progress{:progress="60" class="size-14"}
:::

#code
```vue
<KCircularProgress :progress="60" />
<KCircularProgress :progress="60" class="size-10" />
<KCircularProgress :progress="60" class="size-14" />
```
::

## Customization

Use the `ui` prop to change the classes of each part of the ring: `base` for the SVG, `track` for the background circle and `indicator` for the filled part.

::code-preview
:k-circular-progress{:progress="60" :ui='{"track": "stroke-secondary/15", "indicator": "stroke-secondary"}'}

#code
```vue
<KCircularProgress :progress="60" :ui="{ track: 'stroke-secondary/15', indicator: 'stroke-secondary' }" />
```
::

### Props

| Prop | Type | Default |

| `ui` | `{ base?, track?, indicator? }` | |
| `class` | `string` | |
