---
title: Loading indicator
description: A spinning ring that shows an action is in progress, sized and colored by the surrounding text.
---

## Usage

### Label

Use the `label` prop to set the name announced by screen readers. The default is `Loading`.

::code-preview
:k-loading-indicator{label="Syncing accounts"}

#code
```vue
<KLoadingIndicator label="Syncing accounts" />
```
::

### Size

The indicator is as tall as the font size. Use a `text-*` class to change it.

::code-preview
:::div{class="flex flex-wrap items-center gap-6"}
:k-loading-indicator{class="text-base"} :k-loading-indicator{class="text-xl"} :k-loading-indicator{class="text-2xl"} :k-loading-indicator{class="text-3xl"}
:::

#code
```vue
<KLoadingIndicator class="text-base" />
<KLoadingIndicator class="text-xl" />
<KLoadingIndicator class="text-2xl" />
<KLoadingIndicator class="text-3xl" />
```
::

### Color

The indicator takes the current text color. Use a `text-*` class to change it.

::code-preview
:::div{class="flex flex-wrap items-center gap-6"}
:k-loading-indicator{class="text-xl text-primary"} :k-loading-indicator{class="text-xl text-secondary"} :k-loading-indicator{class="text-xl text-muted"}
:::

#code
```vue
<KLoadingIndicator class="text-primary" />
<KLoadingIndicator class="text-secondary" />
<KLoadingIndicator class="text-muted" />
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | `'Loading'` |
| `ui` | `{ base? }` | |
| `class` | `string` | |
