---
title: Alert
description: A message that draws attention to an event, a risk or something new, with optional actions.
---

## Usage

### Title and description

Use the `title` and `description` props to set the text of the alert. You can set one or both. The `title` and `description` slots replace them.

::code-preview
:::div{class="flex w-full flex-col gap-y-3"}
::::k-alert{title="Your monthly statement is ready" description="October 2026 is available to download as a PDF or CSV."}
::::

::::k-alert{title="Your savings goal is 80% complete." color="success" variant="soft"}
::::

::::k-alert{description="Scheduled transfers run at 9:00 AM in your local time zone."}
::::
:::

#code
```vue
<KAlert
  title="Your monthly statement is ready"
  description="October 2026 is available to download as a PDF or CSV."
/>
<KAlert title="Your savings goal is 80% complete." color="success" variant="soft" />
<KAlert description="Scheduled transfers run at 9:00 AM in your local time zone." />
```
::

### Variant

Use the `variant` prop to change the look of the alert: `outline` (default), `soft` or `solid`.

::code-preview
:::div{class="flex w-full flex-col gap-y-3"}
::::k-alert{title="Your monthly statement is ready" description="October 2026 is available to download as a PDF or CSV."}
::::

::::k-alert{title="Your monthly statement is ready" description="October 2026 is available to download as a PDF or CSV." variant="soft"}
::::

::::k-alert{title="Your monthly statement is ready" description="October 2026 is available to download as a PDF or CSV." variant="solid"}
::::
:::

#code
```vue
<KAlert title="Your monthly statement is ready" description="October 2026 is available to download as a PDF or CSV." />
<KAlert
  title="Your monthly statement is ready"
  description="October 2026 is available to download as a PDF or CSV."
  variant="soft"
/>
<KAlert
  title="Your monthly statement is ready"
  description="October 2026 is available to download as a PDF or CSV."
  variant="solid"
/>
```
::

### Color

Use the `color` prop to change the color of the alert: `primary` (default), `success`, `warning`, `caution`, `danger`, `info` or `discovery`. A `danger` alert gets `role="alert"`, so screen readers announce it right away.

::code-preview
:::div{class="grid w-full gap-3 lg:grid-cols-2"}
::::k-alert{title="Payment sent" description="$1,250.00 is on its way to Jordan Reyes." color="success" variant="soft"}
::::

::::k-alert{title="Card expires soon" description="Your Visa ending in 4821 expires at the end of the month." color="warning" variant="soft"}
::::

::::k-alert{title="Unusual activity" description="We noticed a sign-in from a new device in Lisbon." color="caution" variant="soft"}
::::

::::k-alert{title="Payment failed" description="Your bank declined the transfer. No money left your account." color="danger" variant="soft"}
::::

::::k-alert{title="Exchange rates updated" description="Balances in other currencies now use today's rates." color="info" variant="soft"}
::::

::::k-alert{title="New: budget insights" description="See where your money goes with weekly spending summaries." color="discovery" variant="soft"}
::::
:::

```vue
<KAlert title="Payment sent" description="$1,250.00 is on its way to Jordan Reyes." color="success" variant="soft" />
```

### Icon

Each color has its own icon: a triangle for `warning`, `caution` and `danger`, a check for `success`, and an info circle for the others. Use the `icon` prop to show another [Lucide](https://lucide.dev/guide/packages/lucide-vue-next) icon.

::code-preview
:alert-icon-example

#code
```vue
<script setup lang="ts">
import { Sparkles } from 'lucide-vue-next'
</script>

<template>
  <KAlert
    title="New: budget insights"
    description="See where your money goes with weekly spending summaries."
    color="discovery"
    variant="soft"
    :icon="Sparkles"
  />
</template>
```
::

Set `show-icon` to `false` to hide the icon.

::code-preview
:k-alert{title="Maintenance on November 30" description="Transfers may be delayed between 2:00 and 4:00 AM." variant="soft" :show-icon="false"}

#code
```vue
<KAlert
  title="Maintenance on November 30"
  description="Transfers may be delayed between 2:00 and 4:00 AM."
  variant="soft"
  :show-icon="false"
/>
```
::

### Actions

Use the `actions` slot to add buttons. They sit at the end of the alert, and move below the text when the alert is narrower than 28rem.

::code-preview
:alert-actions-example

#code
```vue
<KAlert
  title="Card expires soon"
  description="Your Visa ending in 4821 expires at the end of the month."
  color="warning"
  variant="soft"
>
  <template #actions>
    <KButton label="Update card" size="sm" variant="outline" color="gray" />
  </template>
</KAlert>

<KAlert
  title="Two-factor authentication is off"
  description="Add a second step at sign-in to keep your accounts safe."
>
  <template #actions>
    <KButton label="Later" size="sm" variant="ghost" color="gray" />
    <KButton label="Turn on" size="sm" />
  </template>
</KAlert>
```
::

### Actions placement

Use the `actions-placement` prop to always put the actions below the text (`bottom`), which suits long descriptions. The default is `end`.

::code-preview
:alert-actions-bottom-example

#code
```vue
<KAlert
  title="Payment failed"
  description="Your bank declined the transfer of $1,250.00 to Jordan Reyes. No money left your account, and you can try again or pay with another card."
  color="danger"
  variant="soft"
  actions-placement="bottom"
>
  <template #actions>
    <KButton label="Try again" size="sm" color="danger" />
    <KButton label="Use another card" size="sm" variant="outline" color="gray" />
  </template>
</KAlert>
```
::

### Close

Use the `closable` prop to add a close button at the end of the alert. A click hides the alert. Use `v-model:open` to know when it was closed, or to show it again. Screen readers name the button with `close-label`, `Close` by default, which you can translate.

::code-preview
:alert-close-example

#code
```vue
<script setup lang="ts">
import { ref } from 'vue'

const isAlertOpen = ref(true)
</script>

<template>
  <KAlert
    v-model:open="isAlertOpen"
    description="Balances are refreshed every 15 minutes."
    color="info"
    variant="soft"
    closable
  />
  <KButton v-if="!isAlertOpen" label="Show the alert again" size="sm" variant="outline" @click="isAlertOpen = true" />
</template>
```
::

## Customization

Use the `ui` prop to change the classes of each part of the alert, and `class` for the root element. Your classes always win: `rounded-none` replaces the default `rounded-xl` instead of being added to it.

::code-preview
:k-alert{title="Square corners" description="The root keeps every other class." variant="soft" :ui='{"root": "rounded-none"}'}

#code
```vue
<KAlert title="Square corners" description="The root keeps every other class." variant="soft" :ui="{ root: 'rounded-none' }" />
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | |
| `description` | `string` | |
| `variant` | `'outline' \| 'soft' \| 'solid'` | `'outline'` |
| `color` | `'primary' \| 'success' \| 'warning' \| 'caution' \| 'danger' \| 'info' \| 'discovery'` | `'primary'` |
| `icon` | `Component` | Depends on `color` |
| `showIcon` | `boolean` | `true` |
| `actionsPlacement` | `'end' \| 'bottom'` | `'end'` |
| `closable` | `boolean` | `false` |
| `closeLabel` | `string` | `'Close'` |
| `open` | `boolean` | `true` |
| `ui` | `{ root?, body?, icon?, content?, wrapper?, title?, description?, actions?, closeButton? }` | |
| `class` | `string` | |

### Slots

| Slot | Description |
| --- | --- |
| `title` | Replaces the title. |
| `description` | Replaces the description. |
| `actions` | Buttons at the end or below the text. |

### Emits

| Event | Payload |
| --- | --- |
| `update:open` | `boolean` |
