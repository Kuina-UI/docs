---
title: Loading dots
description: Three dots that pulse one after the other while content is loading.
---

## Usage

### Label

Use the `label` prop to set the name announced by screen readers. The default is `Loading`.

::code-preview
:k-loading-dots{label="Loading messages"}

#code
```vue
<KLoadingDots label="Loading messages" />
```
::

### Color

The dots take the current text color. Use a `text-*` class to change it.

::code-preview
:::div{class="flex flex-wrap items-center gap-6"}
:k-loading-dots{class="text-primary"} :k-loading-dots{class="text-secondary"} :k-loading-dots{class="text-muted"}
:::

#code
```vue
<KLoadingDots class="text-primary" />
<KLoadingDots class="text-secondary" />
<KLoadingDots class="text-muted" />
```
::

## API

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | `'Loading'` |
| `ui` | `{ base? }` | |
| `class` | `string` | |
