---
title: useRowSelection
description: Select records one by one or all at once, and keep their keys, for a table or any other list.
---

## Usage

`useRowSelection` is the selection of the [Table](/components/data/table). Use it on its own for a list of cards with checkboxes, for example.

```vue
<script setup lang="ts">
const selectedTransactionIds = ref<string[]>([])

const { selectionState, isRowSelected, toggleRow, toggleAllRows } = useRowSelection(
  visibleTransactions,
  selectedTransactionIds,
  { isRowSelectable: (transaction) => transaction.status !== 'Failed' },
)
</script>

<template>
  <KCheckbox
    label="Select all"
    :model-value="selectionState === 'all'"
    :indeterminate="selectionState === 'some'"
    @update:model-value="toggleAllRows"
  />
  <KCheckbox
    v-for="transaction in visibleTransactions"
    :key="transaction.id"
    :label="transaction.merchant"
    :model-value="isRowSelected(transaction)"
    @update:model-value="(isSelected) => toggleRow(transaction, isSelected)"
  />
</template>
```

The keys are read from `id`, or from `rowKey`, a field name or a function. "All" covers the records you give, like the current page: selecting them all keeps the keys of records on other pages.

With the Nuxt module, `useRowSelection` is auto-imported. In a Vue app, import it from `@kuina-ui/vue`.

## API

```ts
useRowSelection(rows, selectedRowKeys, options?)
```

### Options

| Option | Type | Default |
| --- | --- | --- |
| `rowKey` | `keyof Row \| (row) => string \| number` | `'id'` |
| `isRowSelectable` | `(row) => boolean` | |

### Returned values

| Value | Type |
| --- | --- |
| `selectionState` | `ComputedRef<'none' \| 'some' \| 'all'>` |
| `selectedRowCount` | `ComputedRef<number>` |
| `isRowSelected` | `(row) => boolean` |
| `isRowSelectable` | `(row) => boolean` |
| `toggleRow` | `(row, shouldSelect?) => void` |
| `toggleAllRows` | `(shouldSelect?) => void` |
| `clearSelection` | `() => void` |
